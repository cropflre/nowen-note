# Nowen Note 隐私权政策

**最后更新日期：2026 年 8 月 11 日**

Nowen Note 是一个开源、自托管的笔记与知识管理项目。本政策说明 Nowen Note 桌面端/服务端以及 Nowen Note Web Clipper 如何处理用户数据。项目不会因为 Windows 代码签名而把用户笔记、账号、附件或配置发送给 SignPath。

## 1. 桌面端与服务端

### 1.1 数据存储与处理

- 笔记、附件、账号、工作区、任务等数据默认由用户选择的本地环境或自托管 Nowen Note 服务处理。
- 用户自行决定服务器、数据库、附件存储与备份位置，并负责其部署环境的访问控制与数据安全。
- 卸载桌面客户端不会自动删除用户自托管服务器上的数据；本地配置与本地数据可由用户按操作系统和部署方式自行清除。

### 1.2 网络连接

Nowen Note 只在相关功能需要时连接对应服务：

- **自动更新**：桌面端检查更新时访问 Nowen Note 官方 GitHub Release。
- **远程 Nowen Note 服务**：仅在用户主动配置远程/局域网服务器后连接该地址。
- **AI 服务**：仅在用户配置并使用 OpenAI 兼容接口、通义千问、Gemini、DeepSeek、豆包、Ollama 等服务时，把完成该功能所需的内容发送到用户选择的服务商。
- **对象存储**：仅在用户配置 S3、Cloudflare R2、MinIO 等对象存储后传输相关附件。
- **备份与同步服务**：仅在用户配置 WebDAV、邮件或其他远程服务并启用相应功能时连接。

第三方服务如何保存和处理数据，受用户所选择服务商的条款与隐私政策约束。使用涉及敏感内容的第三方服务前，请先确认其数据处理规则。

### 1.3 Windows 代码签名

Nowen Note 的正式 Windows 发布包可通过 SignPath.io / SignPath Foundation 提供的代码签名流程签名。代码签名只处理 GitHub Actions 从本仓库已提交源码产生的构建产物，不会把用户笔记、附件、账号、Token、AI 对话或自托管服务数据发送给 SignPath。

### 1.4 数据安全与用户控制

- 公网访问自托管服务时建议使用 HTTPS，并妥善保护账号、Token、数据库、附件和备份。
- 用户可以修改或删除本地客户端配置，也可以在自托管服务中管理、导出或删除自己的数据。
- 第三方 AI、对象存储、WebDAV、邮件和远程服务器均由用户主动配置；Nowen Note 无法替代这些第三方服务自身的安全和隐私责任。

## 2. Nowen Note Web Clipper

Nowen Note Web Clipper（以下简称“本扩展”）是一款浏览器扩展，用于将网页内容剪藏到用户自托管的 Nowen Note 笔记服务。

### 2.1 数据收集与使用

本扩展**仅在用户主动触发剪藏操作时**收集以下数据：

- **网页内容**：当前页面的正文文字、图片、HTML 结构，用于生成笔记内容。
- **网页元信息**：当前页面的标题和 URL，用于标注笔记来源。
- **屏幕截图**：仅在用户选择截图模式时，截取当前页面的可视区域或整页长图。

以上数据**仅用于**完成剪藏功能，即将内容保存到用户自己配置的 Nowen Note 服务器。

### 2.2 用户配置数据

本扩展在浏览器本地（chrome.storage）存储以下配置信息：

- Nowen Note 服务器地址
- API Token（用于身份验证）
- 默认笔记本名称、标签、输出格式等偏好设置

这些数据**仅存储在用户浏览器本地**，不会上传到开发者服务器。

### 2.3 数据传输

本扩展收集的网页内容和截图**仅发送到用户自行配置的 Nowen Note 服务器**。本扩展：

- ❌ **不会**将剪藏内容发送到开发者控制的第三方服务器
- ❌ **不会**为了广告或画像收集、存储或传输用户的个人身份信息
- ❌ **不会**追踪用户的浏览历史或浏览行为
- ❌ **不会**在后台自动收集网页内容
- ❌ **不会**出售用户数据

### 2.4 第三方服务

本扩展不使用第三方广告或追踪服务。剪藏数据的传输目标由用户自行配置；若目标 Nowen Note 服务又启用了 AI、对象存储、WebDAV 等第三方功能，则这些后续处理受该服务端配置及相应第三方条款约束。

### 2.5 权限说明

| 权限 | 用途 |
|------|------|
| activeTab | 访问用户主动触发剪藏时的当前标签页 |
| scripting | 注入内容提取脚本以获取网页正文 |
| contextMenus | 在右键菜单中提供剪藏快捷入口 |
| storage | 在浏览器本地保存用户配置 |
| notifications | 在截图等场景下通知用户操作结果 |
| debugger | 仅用于整页长截图功能（CDP 协议） |
| host_permissions | 支持在任意网页上执行剪藏和下载图片 |

所有权限仅在用户主动操作对应功能时使用，不会用于后台持续采集网页内容。

### 2.6 数据安全与用户控制

- 用户的 API Token 仅存储在浏览器本地 chrome.storage 中。
- 与 Nowen Note 服务器通信时建议使用 HTTPS 加密连接。
- 本扩展不包含任何远程加载的代码。
- 用户可随时在扩展选项页修改或删除已保存的配置。
- 卸载扩展将由浏览器清除其本地扩展存储数据。
- 用户完全控制数据的传输目标（自托管服务器地址）。

## 3. 政策变更

如本隐私政策发生变更，我们将在此页面更新内容和日期。涉及新的数据处理边界或第三方服务时，会在相关文档中同步说明。
