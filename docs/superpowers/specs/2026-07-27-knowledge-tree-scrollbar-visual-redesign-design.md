# 知识树滚动条视觉重设计

## 背景

Web 端和桌面端知识树当前使用自定义滚动条，以避免 Chromium 与 Windows 自动隐藏原生滚动条。现有滑块视觉宽度接近整个交互轨道，颜色和体量都偏重，在浅色侧栏中形成明显的竖向灰条。

## 目标与范围

- Web 端和桌面端知识树统一采用“静谧胶囊”滚动条。
- 提升视觉精致度，同时保留常驻可发现性、拖动能力和键盘聚焦反馈。
- 移动端继续使用原生触控滚动，不显示自定义轨道。
- 不改变知识树结构、滚动计算、拖动算法或当前正在进行的性能修复。
- 不扩展到应用中的其他滚动区域。

## 视觉规格

- 轨道交互热区宽度保持 `9px`，放置于知识树右侧 `2px` 位置，避免降低鼠标命中率。
- 滑块默认宽度为 `4px`，在轨道内水平居中，使用全圆角胶囊造型。
- 默认滑块使用现有 `--pm-scrollbar` 颜色，并通过透明度降低视觉重量。
- 悬停、键盘聚焦或拖动时，滑块扩展为 `6px`，切换为 `--pm-scrollbar-hover` 并提高透明度。
- 轨道默认透明；交互状态下仅显示由 `--pm-scrollbar` 混合出的低对比背景，不使用边框或阴影。
- 滑块最小高度继续保持 `36px`，确保短文档和长文档都可操作。
- 不可滚动时保留轨道 DOM 与布局，但滑块透明且不可拖动，避免错误暗示和布局抖动。
- 明暗主题均复用现有主题变量，不增加独立硬编码色板。

## 交互状态

1. **静止且可滚动：** `4px` 低对比滑块常驻，轨道透明。
2. **悬停或键盘聚焦：** 滑块平滑扩展到 `6px`，轨道出现极淡底色。
3. **拖动：** 保持 `6px` 高对比滑块，光标由 `grab` 切换为 `grabbing`。
4. **不可滚动：** 滑块透明，轨道不响应拖动并保持 `aria-disabled="true"`。
5. **移动端：** 自定义轨道保持隐藏，不影响原生惯性滚动。

## 实现边界

视觉调整集中在 `knowledgeTreeScrollbarBridge.ts` 注入的自定义轨道样式中；同步对 `Sidebar.tsx` 内的原生滚动条兜底样式做相同的宽度、圆角和颜色收敛。当前工作区已有的重新挂载、显式刷新和尺寸约束改动原样保留。

## 验证

- 更新滚动条样式契约测试，锁定默认宽度、交互宽度、透明轨道和不可滚动状态。
- 运行知识树滚动条聚焦 Vitest。
- 运行前端生产构建。
- 在 Web 端与 Electron 桌面端检查默认、悬停、拖动、不可滚动和暗色主题状态；移动端确认不出现自定义轨道。
