# 从语雀导入文件

进入「设置 → 数据管理 → 导入 → 语雀」，选择语雀导出的 `.md`、`.markdown` 或包含 Markdown 的 ZIP。ZIP 无需解压，单个文件上限 100 MB。

1. 默认选择全部文档，可以取消整个知识库，或展开「选择部分文档」。
2. 确认目标空间和目录。默认保存到「语雀导入」，按导出文件目录创建子目录。
3. 点击「开始导入」。保持页面打开，完成后点击「查看导入的笔记」。失败项可以单独重试。

Markdown 正文原样保留，包内能唯一匹配的图片随正文保存。外部图片保留原链接；缺失资源、SVG 和非图片附件会提示，本版不自动迁入这些资源。暂不支持语雀专有格式、PDF、HTML，也没有 Cookie、API Token 或在线账号连接。

相同账号、空间、目标、来源路径和内容会得到相同的导入标识。再次导入或重试时跳过已有笔记，包括之后在 Nowen 中编辑过的笔记。来源内容或包内图片变化时创建新副本，不覆盖已有笔记。更改导出目录名称或目标会被视为不同来源/目标；文件路线没有语雀文档的官方 ID。

目录依据导出包的路径恢复，不能保证恢复导出包未包含的语雀目录顺序、权限或文档类型。当前流程不提供语雀与 Nowen 的持续同步。Android 沿用普通笔记的本机保存与同步队列。
