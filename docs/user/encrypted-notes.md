# 加密笔记（试用）

当前支持网页版和桌面端。移动应用暂不支持创建或解锁；网页版需要 HTTPS，本机 localhost 除外。

## 整篇笔记

1. 在左侧“新建”菜单选择“加密笔记”。
2. 填写标题、选择格式，设置并确认密码，然后点击“创建”。新密码至少 12 个字符，推荐使用长口令；已有笔记的旧短密码仍可解锁。
3. 打开笔记，输入密码并点击“解锁”，即可编辑正文。
4. 修改后停止输入，系统会自动保存。服务器确认后显示“已保存”；离线密文已写入本机队列时显示“已保存在本机，等待同步”。联网后自动同步。

点击“锁定”会先隐藏正文，保存最新修改后清除会话，再次打开需要输入密码。保存期间仍可编辑，后续修改会继续自动保存。修改密码时，先等待正文保存并完成同步，再展开“修改密码”，验证当前密码并填写新密码。

## 局部内容

在 Markdown 的空白行或富文本普通段落的光标处，点击“插入加密内容”。在弹窗里输入新内容，设置并确认密码，然后点击“保存”。周围的普通正文保持可见。

已有文字：选中普通文本，点击选区菜单中的“加密”，设置并确认密码，然后点击“加密”。选中内容会替换成锁定卡片，由笔记自动保存；富文本保留选中的基础格式。关闭弹窗不会修改原文。图片、附件、链接、代码块和已加密区域不能混在选区里。

**选区加密只保护当前正文。旧历史、旧备份、其他设备或导出副本可能仍含明文，不会自动清理或一起加密。** 为避免通过撤销恢复刚加密的文字，成功替换后会清除当前编辑器的撤销/重做记录。需要保护从未保存过的内容时，请直接使用“插入加密内容”。

之后点击“🔒 加密内容”卡片，输入密码并按 Enter 或点击“解锁”。解锁后直接修改内容，点击“保存”，由笔记原有的保存流程保存。可编辑的 Markdown 预览和富文本都支持从卡片直接编辑，无需切换源码；只读笔记只能查看。

原笔记或权限变化时会拒绝覆盖，当前修改仍保留在弹窗中。

## 保存和自动锁定

整篇加密笔记会自动保存。5 分钟无操作、切到其他窗口或应用进入后台时，系统会先保存再锁定。锁定期间显示“正在锁定…”，完成后需要重新输入密码。切换笔记时若保存尚未完成，请稍候再切换。

保存失败时，锁定不会完成，修改继续隐藏并暂存在会话中。重新输入密码后可以恢复修改，再点击“重试保存”或“锁定”；密码错误不会显示草稿。如需丢弃当前修改，选择“放弃修改并锁定”并确认。离线保存完成后仍需联网同步；修改密码前请等待同步完成。

局部内容弹窗仍需点击“保存”；其未保存修改在自动锁定后仅暂存在会话中，重新输入密码可恢复。加密操作失败时修改也保持隐藏，不会自动恢复正文。关闭页面、关闭局部内容弹窗、切换账号或强制退出可能丢失尚未完成保存的修改，请先等待保存完成。关闭浏览器时不能保证异步保存完成。

保存失败时不要关闭页面，保留修改并重试。出现版本冲突时，到同步中心选择“保留本机版本”或“保留云端版本”；另一版本会保留在历史记录中。

## 需要知道的限制

- **忘记加密密码无法恢复。** 找回账号不能恢复正文。
- 仅正文加密，标题、目录、标签等信息仍可见。
- 目前仅支持文本，区域内图片、附件和嵌入暂不支持；整篇加密笔记暂不支持分享、服务端正文搜索、AI 和多人协作。
- 已有普通笔记整篇转换尚未开放。选中文字加密不会清理旧明文历史、导出、协作数据或备份；修改密码后，以前的加密备份仍需使用当时的密码。
- 含局部加密内容的笔记，请升级所有客户端后再编辑。

已有笔记整篇加密及局部编辑自动保存仍在完善中，见 [功能进度](../architecture/encrypted-notes-epic.md)。
