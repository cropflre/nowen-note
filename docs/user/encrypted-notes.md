# 加密笔记（试用）

当前支持网页版和桌面端。移动应用暂不支持创建或解锁；网页版需要 HTTPS，本机 localhost 除外。

## 整篇笔记

1. 在左侧“新建”菜单选择“加密笔记”。
2. 填写标题、选择格式，设置并确认密码，然后点击“创建”。密码至少 12 个字符。
3. 打开笔记，输入密码并点击“解锁”，即可编辑正文。
4. 修改后停止输入约 800 毫秒，系统会自动加密保存，也可点击“保存”立即保存。显示“已保存”表示服务器已确认；显示“已保存到本机，联网后同步”表示尚待同步。

点击“锁定”会先保存最新修改，再清除正文和密码，再次打开需要输入密码。保存期间仍可编辑，后续修改会继续自动保存。修改密码时，先等待正文保存并完成同步，再展开“修改密码”填写新密码。

## 局部内容

在 Markdown 的空白行或富文本普通段落的光标处，点击“插入加密内容”。在弹窗里输入新内容，设置并确认密码，然后点击“保存”。周围的普通正文保持可见。

已有文字：选中普通文本，点击选区菜单中的“加密”，设置并确认密码，然后点击“加密”。选中内容会替换成锁定卡片，由笔记自动保存；富文本保留选中的基础格式。关闭弹窗不会修改原文。图片、附件、链接、代码块和已加密区域不能混在选区里。

**选区加密只保护当前正文。旧历史、旧备份、其他设备或导出副本可能仍含明文，不会自动清理或一起加密。** 为避免通过撤销恢复刚加密的文字，成功替换后会清除当前编辑器的撤销/重做记录。需要保护从未保存过的内容时，请直接使用“插入加密内容”。

之后点击卡片上的“解锁”，输入密码并按 Enter 或点击“解锁”。解锁后直接修改内容，点击“保存”，由笔记原有的保存流程保存。可编辑的 Markdown 预览和富文本都支持从卡片直接编辑，无需切换源码；只读笔记只能查看。

“复制加密内容”复制的是加密后的内容，粘贴的副本仍使用同一密码。原笔记或权限变化时会拒绝覆盖，当前修改仍保留在弹窗中。

## 保存和自动锁定

整篇加密笔记会自动保存。系统会在 5 分钟无操作、窗口失去焦点、页面隐藏或桌面窗口最小化时保存后锁定。锁定期间正文编辑器隐藏，系统等待正在进行的保存，再保存期间产生的新修改；只有服务器确认密文或本机离线队列持久化成功后才显示锁定完成。

加密或保存失败时，锁定不会完成，正文编辑器重新显示并保留修改，请点击“保存”或“重试锁定”。系统暂停自动重试，避免反复覆盖版本冲突；再次编辑也不会偷偷重试。离线保存只有在密文已写入本机队列并读回核对后才算完成，仍需联网同步。

局部内容弹窗仍需点击“保存”；其未保存修改在自动锁定后仅暂存在会话中，重新输入密码可恢复。关闭页面、关闭局部内容弹窗、切换账号或强制退出可能丢失尚未完成保存的修改，请先等待保存完成。关闭浏览器时不能保证异步保存完成。

保存失败时不要关闭页面，保留修改并重试。出现版本冲突时，到同步中心选择保留本机或服务器版本；加密内容不能自动合并。

## 需要知道的限制

- **忘记加密密码无法恢复。** 找回账号不能恢复正文。
- 仅正文加密，标题、目录、标签等信息仍可见。
- 目前仅支持文本，区域内图片、附件和嵌入暂不支持；整篇加密笔记暂不支持分享、服务端正文搜索、AI 和多人协作。
- 已有普通笔记整篇转换尚未开放。选中文字加密不会清理旧明文历史、导出、协作数据或备份；修改密码后，以前的加密备份仍需使用当时的密码。
- 含局部加密内容的笔记，请升级所有客户端后再编辑。

普通笔记菜单不再显示内部“转换前检查”，将来由转换流程自动完成检查。技术边界及验收进度见 [加密 Epic](../architecture/encrypted-notes-epic.md) 和 [已有笔记转换](../architecture/encrypted-notes-m4.md)。
