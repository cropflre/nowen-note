# 加密笔记（试用）

当前支持网页版和桌面端。移动应用暂不支持创建或解锁；网页版需要 HTTPS，本机 localhost 除外。

## 整篇笔记

1. 在左侧“新建”菜单选择“加密笔记”。
2. 填写标题、选择格式，设置并确认密码，然后点击“创建”。新密码至少 6 个字符，推荐使用长口令；已有笔记的旧短密码仍可解锁。
3. 打开笔记，输入密码并点击“解锁”，即可编辑正文。
4. 修改后停止输入，系统会自动保存。服务器确认后显示“已保存”；离线密文已写入本机队列时显示“已保存在本机，等待同步”。联网后自动同步。

点击“锁定”会先隐藏正文，保存最新修改后清除会话，再次打开需要输入密码。保存期间仍可编辑，后续修改会继续自动保存。修改密码时，先等待正文保存并完成同步，再展开“修改密码”，验证当前密码并填写新密码。

### 不再需要加密

解锁笔记并等待修改保存后，展开底部“解除加密”，再次输入当前加密密码，勾选明文保存确认，再点击“确认解除加密”。正文和历史版本会在原位置恢复为普通 Markdown 或富文本笔记，保留笔记 ID、标题、目录、标签及历史版本，以后打开无需密码。

解除后正文会以明文保存，并可参与搜索、同步和备份；已有加密备份不会改变，仍需原密码。密码只在本机验证，不发送到服务端。错误密码、版本冲突或历史解密失败时，不修改服务端密文；操作中断或连接异常时，请保留页面重试，或重新打开笔记确认状态。

目前支持 Web/桌面端的个人文本整篇加密笔记，包括旧版加密笔记和通过“加密已有笔记”转换的笔记。请先完成未保存修改和同步，关闭其他编辑窗口；配置了同步 Profile 的服务器及原生移动端暂不支持原地解除加密。超过 1000 条历史或正文与密文历史总量超过 32 MiB 时也会拒绝转换，以保留原数据。

## 加密已有笔记

在个人 Markdown 或基础富文本笔记右上角“更多”中选择“加密笔记”。系统会先检查正文、历史版本、共享、同步和本机未保存修改。检查通过后设置并确认密码，阅读旧副本提示，再点击“加密”。笔记保持原来的位置、ID、标题和标签；正文和已有历史版本转为密文，确认保存并清理本机已保存的旧副本后显示锁定页。

转换期间请保持页面打开。连接中断或本机清理失败时，会保留加密进度供“继续完成加密”，不会把已提交的笔记恢复成明文。服务端尚未加密时可以“取消未完成加密”，保留原正文和本机修改；已加密时必须继续确认和清理。

首版拒绝图片、附件、嵌入、已有加密区域、复杂富文本及含这些内容的历史版本，也拒绝工作空间、分享、模板、AI 引用、双向链接、文件夹同步等关联。服务器配置了同步 Profile 时暂不提供既有笔记转换。正文与历史合计超过 8 MiB 或已有历史超过 100 条也暂不支持。请先保存并同步修改、解决冲突、关闭其他编辑窗口，再重试检查。

解锁后点击“版本历史”，选择版本即可在隔离的只读区域查看转换前后的内容；锁定会同时隐藏历史正文。历史恢复入口仍待完善。

**转换清理当前服务器和当前浏览器中应用控制的逻辑副本，不承诺物理擦除数据库/WAL/磁盘，也无法追回旧备份、导出和其他设备的旧明文。**

## 局部内容

在 Markdown 的空白行或富文本普通段落的光标处，点击“插入加密内容”。在弹窗里输入新内容，设置并确认密码，然后点击“保存”。周围的普通正文保持可见。

已有文字：选中普通文本，点击选区菜单中的“加密”，设置并确认密码，然后点击“加密”。选中内容会替换成锁定卡片，由笔记自动保存；富文本保留选中的基础格式。关闭弹窗不会修改原文。图片、附件、链接、代码块和已加密区域不能混在选区里。

**选区加密只保护当前正文。旧历史、旧备份、其他设备或导出副本可能仍含明文，不会自动清理或一起加密。** 为避免通过撤销恢复刚加密的文字，成功替换后会清除当前编辑器的撤销/重做记录。需要保护从未保存过的内容时，请直接使用“插入加密内容”。

之后点击“🔒 加密内容”卡片，输入密码并按 Enter 或点击“解锁”。解锁后直接修改内容，点击“保存”，由笔记原有的保存流程保存。可编辑的 Markdown 预览和富文本都支持从卡片直接编辑，无需切换源码；只读笔记只能查看。

原笔记或权限变化时会拒绝覆盖，当前修改仍保留在弹窗中。

## 保存和自动锁定

整篇加密笔记会自动保存。5 分钟无操作、切到其他窗口或应用进入后台时，系统会先保存再锁定。锁定期间显示“正在锁定…”，完成后需要重新输入密码。切换笔记时若保存尚未完成，请稍候再切换。

保存失败时，锁定不会完成，修改继续隐藏并暂存在会话中。重新输入密码后可以恢复修改，再点击“重试保存”或“锁定”；密码错误不会显示草稿。如需丢弃当前修改，选择“放弃修改并锁定”并确认。离线保存完成后仍需联网同步；修改密码前请等待同步完成。

局部内容弹窗仍需点击“保存”；其未保存修改在自动锁定后仅暂存在会话中，重新输入密码可恢复。加密操作失败时修改也保持隐藏，不会自动恢复正文。关闭页面、关闭局部内容弹窗、切换账号或强制退出可能丢失尚未完成保存的修改，请先等待保存完成。关闭浏览器时不能保证异步保存完成。

保存失败时不要关闭页面，保留修改并重试。出现版本冲突时，到同步中心选择“保留本机版本”或“保留云端版本”；另一版本会保留在历史记录中。

## 需要知道的限制

- **忘记加密密码无法恢复。** 找回账号不能恢复正文。
- 仅正文加密，标题、目录、标签等信息仍可见。
- 目前仅支持文本，区域内图片、附件和嵌入暂不支持；整篇加密笔记暂不支持分享、服务端正文搜索、AI 和多人协作。
- 已有笔记整篇转换目前限个人基础文本及受支持历史，详见上节。选中文字加密不会清理旧明文历史、导出、协作数据或备份；修改密码后，以前的加密备份仍需使用当时的密码。
- 含局部加密内容的笔记，请升级所有客户端后再编辑。

复杂内容转换、局部编辑自动保存、统一隐私密码及原生移动端仍在完善中，见 [功能进度](../architecture/encrypted-notes-epic.md)。
