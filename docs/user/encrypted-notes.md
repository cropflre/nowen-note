# 加密文本笔记（实验性）

在左侧知识树的“新建”菜单选择“加密文本笔记（实验性）”，选择 Markdown 或基础富文本，输入两次至少 12 个字符的口令并确认限制。创建需要服务器确认；新笔记默认锁定。Web 部署要求 HTTPS（本机 localhost 除外）。当前提供 Web/桌面实验入口，Android/iOS 参数尚未真机验收，因此移动应用禁止创建、解锁。

输入口令解锁后，正文只在当前编辑会话中可见。修改后点击“加密保存”，界面显示服务器确认或离线队列保存状态。此入口使用手动保存，尚未加密的编辑不会自动持久化。关闭页面前先保存；未保存时切换笔记/视图或关闭标签会被阻止，也可以明确“放弃修改并锁定”。浏览器刷新/关闭会提示未保存，但无法阻止进程崩溃、强制退出或系统清理内存，未保存的修改可能丢失。

保存遇到网络中断时，客户端先加密，再将密文写入当前服务器/账号的既有离线队列，读回确认成功后允许锁定。重新打开时优先读取待同步密文。空间不足或持久化失败时不会报告保存成功，请保持页面并重试。版本冲突保留本地密文，停止自动覆盖；需在同步中心明确选择本机或服务器版本。Sync V2 冲突历史保留两侧密文，加密正文不支持智能合并或普通 JSON 手动合并。未同步到服务器前不能修改口令。

“锁定”销毁当前文本编辑器（包含富文本撤销栈），释放会话中的正文和口令；切换账号/服务器也会清理。Web/桌面在 5 分钟无操作、窗口失去焦点、页面隐藏或离开时触发自动锁定。有未保存修改时，先将临时编辑器移除，使用原口令在 Worker 中加密为仅内存草稿；完成后需要重新输入口令才能恢复，之后仍需点击“加密保存”。它不会自动提交服务器或写入本地存储。离开笔记/关闭页面会提示未保存，但崩溃、强制退出或切换账号仍会丢失这个内存草稿。若加密失败，则保留编辑并明确提示“自动锁定未完成”，请保存或点击“重试自动锁定”；不要把此提示视为已锁定。JS 引擎无法保证物理内存擦除。

仅正文加密。标题、标签、目录、时间、颜色等元数据可见。附件、图片、嵌入、公开分享、服务端正文搜索/AI、多人协作和解密插件接口暂不支持；Markdown 中的图片/附件语法与富文本非基础节点会拒绝保存。账号权限、目录密码、`isLocked` 与正文加密具有不同作用。

口令丢失无法恢复正文；账号找回不能代替解密口令。在解锁状态下通过“修改口令”填写新口令并等待服务器确认，原正文密文不变，仅重新包装内容密钥。旧备份仍使用旧口令，改口令无法撤销已有副本中的内容密钥。请保存对应备份的口令，并在测试环境验证恢复。数据库或密文备份直接读取无法得到正文，但本功能不防护被控制的客户端、恶意前端更新、截图或用户主动复制出的明文。

此阶段只允许新建加密文本笔记，禁止将既有普通笔记直接转换。已有明文历史、索引、缓存、WAL、附件和旧备份的处理属于后续转换阶段；局部内容加密现提供下述实验入口。[Epic #796](https://github.com/cropflre/nowen-note/issues/796) 和 [验收记录](../architecture/encrypted-notes-m2.md) 跟踪剩余工作。


## 局部加密区域（实验性）

普通 Markdown 笔记在空白行点击“加密区域”；富文本笔记在普通段落的光标处点击工具栏锁图标“新增加密区域”。在临时编辑区输入新内容、两次口令并确认限制，点击“加密写回”。这一步将密文放入笔记，仍需等待笔记原有保存流程完成。区域周围的正文保持公开，可以照常搜索、分享和导出。

锁定卡片点击“查看加密区域”，输入对应口令解锁。富文本可在弹窗内修改并加密写回；Markdown 预览为只读，修改时在源码中将光标放入原加密围栏，再点击“加密区域”。“复制密文”只复制围栏和 envelope，粘贴的副本继续使用同一口令。格式转换保留密文；错误口令、区域被外部修改或写回失败时不会覆盖原区域。

区域弹窗使用相同的 5 分钟闲置/后台自动锁定策略。未写回内容加密成仅内存草稿，不修改主文档；重新输入区域口令恢复后，仍需“加密写回”并等待笔记保存。关闭弹窗前会确认放弃草稿；新区域尚未设置有效口令、内容不受支持或加密失败时，不能完成自动锁定，会保留内容并显示错误。切换账号/服务器或强制退出会丢失未写回草稿。

仅保护临时编辑区内新输入的文本，不提供已有普通明文选区转换，也不清理过去的历史、缓存、WAL 和备份。区域内图片、附件、嵌入暂不支持。新版 notes 保存、Sync V2、块级 Patch 和数据库存储守卫会拒绝不支持区域加密的旧客户端覆盖正文；保存含区域的笔记前请升级所有客户端。含区域的笔记暂不启用实时 Yjs 协作。遇到区域冲突时需要明确选择完整本机或服务器版本，不能自动或手动合并密文。源码编辑仍能主动删除区域；请保留密文备份。移动应用暂禁用创建/解锁，完整产品双设备验收仍待完成，见 [M3 验收记录](../architecture/encrypted-notes-m3.md)。
