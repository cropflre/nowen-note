# 加密笔记（试用）

当前支持网页版和桌面端。移动应用暂不支持创建或解锁；网页版需要 HTTPS，本机 localhost 除外。

## 整篇笔记

1. 在左侧“新建”菜单选择“加密笔记”。
2. 填写标题、选择格式，设置并确认密码，然后点击“创建”。密码至少 12 个字符。
3. 打开笔记，输入密码并点击“解锁”，即可编辑正文。
4. 修改后点击“保存”。显示“已保存”表示服务器已确认；显示“已保存到本机，联网后同步”表示尚待同步。

点击“锁定”隐藏正文，再次打开需要输入密码。修改密码时，先保存正文并完成同步，再展开“修改密码”填写新密码。

## 局部内容

在 Markdown 的空白行或富文本普通段落的光标处，点击“插入加密内容”。在弹窗里输入新内容，设置并确认密码，然后点击“保存”。周围的普通正文保持可见。

之后点击卡片上的“解锁”，输入密码并按 Enter 或点击“解锁”。解锁后直接修改内容，点击“保存”，由笔记原有的保存流程保存。可编辑的 Markdown 预览和富文本都支持从卡片直接编辑，无需切换源码；只读笔记只能查看。

“复制加密内容”复制的是加密后的内容，粘贴的副本仍使用同一密码。原笔记或权限变化时会拒绝覆盖，当前修改仍保留在弹窗中。

## 保存和自动锁定

**整篇加密笔记目前仍需手动点击“保存”。** 系统会在 5 分钟无操作、窗口失去焦点、页面隐藏或桌面窗口最小化时自动锁定。

未保存的修改会暂存在当前会话中，重新输入密码可恢复，之后仍需保存。关闭页面、关闭局部内容弹窗、切换账号或强制退出可能丢失这些修改，请先保存。锁定失败时会保留编辑并提示重试，不代表已经锁定。

保存失败时不要关闭页面，保留修改并重试。出现版本冲突时，到同步中心选择保留本机或服务器版本；加密内容不能自动合并。

## 需要知道的限制

- **忘记加密密码无法恢复。** 找回账号不能恢复正文。
- 仅正文加密，标题、目录、标签等信息仍可见。
- 目前仅支持文本，区域内图片、附件和嵌入暂不支持；整篇加密笔记暂不支持分享、服务端正文搜索、AI 和多人协作。
- 目前只能新建加密笔记或插入新的加密内容，已有普通笔记和选中文字直接加密尚未开放。旧明文历史、导出和备份不会因此加密；修改密码后，以前的加密备份仍需使用当时的密码。
- 含局部加密内容的笔记，请升级所有客户端后再编辑。

自动加密保存和可靠保存后锁定是下一步。普通笔记菜单不再显示内部“转换前检查”，将来由转换流程自动完成检查。技术边界及验收进度见 [加密 Epic](../architecture/encrypted-notes-epic.md) 和 [已有笔记转换](../architecture/encrypted-notes-m4.md)。
