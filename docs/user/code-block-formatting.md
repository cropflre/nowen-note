# 代码块格式化

将代码粘贴到代码块后，在右上角点击「格式化」，整理缩进和换行。格式化结果会写入笔记，沿用编辑器的自动保存；按一次撤销可恢复格式化前的内容。

- 支持 JSON、JavaScript/JSX、TypeScript/TSX、HTML、CSS/SCSS/LESS、YAML。
- 先选择代码块语言。未指定语言或选择纯文本时，只尝试识别 JSON。
- 富文本代码块、Markdown 预览/分屏/实时预览中均可使用。Markdown 源码模式下，将光标放进代码块即可显示按钮。
- 暂不支持的语言按钮不可用。只读笔记不能格式化。
- 语法错误或处理期间内容已变更，会提示原因并保留原文。

格式化在设备本地运行，不向服务器发送代码。格式化器随应用打包并按需加载，适用于 Web、自托管和 Electron；移动端沿用同一编辑器功能。
