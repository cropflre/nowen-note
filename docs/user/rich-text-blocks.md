# 富文本块操作

富文本编辑器支持分栏、高亮提示块、折叠块、表情和代码块标题。

- 在正文中输入 `/`，从插入菜单选择分栏、高亮块或折叠块。
- 桌面上悬停正文左侧的块柄，可拖动排序；点击块柄打开块操作。手机可使用工具栏的「块操作」按钮。
- 块操作提供转换、复制、剪切、粘贴、删除和在下方添加。可能丢失内容的转换会保留原文并提示原因；剪切失败时保留原块。
- 桌面上拖动栏的右边缘调整宽度，悬停栏后使用浮动菜单添加或删除栏。手机上各栏按顺序竖排显示。
- 高亮块可通过调色按钮切换样式。折叠块可以编辑标题，点击箭头展开或收起正文。
- 输入 `:smile` 等表情名称选择候选，也可以直接输入系统表情。
- 代码块顶部可填写标题；回车确认，Esc 取消当前标题修改。

分栏、高亮块、折叠块和带标题的代码块在 Markdown 中保留为 HTML，以保存内部结构。外部 Markdown 工具的显示效果取决于其 HTML 支持。

这些能力使用 Web、桌面端和 Android 共用的富文本编辑器；只读状态不能修改内容。
