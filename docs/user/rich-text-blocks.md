# 富文本块操作

富文本编辑器支持分栏、高亮提示块、文本框、折叠块、表情和代码块标题。

- 在正文中输入 `/`，从插入菜单选择分栏、高亮块、文本框或折叠块。
- 桌面上悬停正文左侧的块柄，可拖动排序；点击块柄打开块操作。手机可使用工具栏的「块操作」按钮。
- 块操作提供转换、复制、剪切、粘贴、删除和在下方添加。可能丢失内容的转换会保留原文并提示原因；剪切失败时保留原块。
- 桌面上拖动栏的右边缘调整宽度，悬停栏后使用浮动菜单添加或删除栏。手机上各栏按顺序竖排显示。
- 高亮块可通过调色按钮切换样式。折叠块可以编辑标题，点击箭头展开或收起正文。
- 输入 `:smile` 等表情名称选择候选，也可以直接输入系统表情。
- 代码块顶部可填写标题；回车确认，Esc 取消当前标题修改。

## 文本框

文本框浮动在正文一侧，后面的段落和标题从旁边环绕，适合杂志式的图文排版：框里可以放文字、图片和列表。

- 输入 `/文本框`，或在块操作的「转换为」「在下方添加」里选择「文本框」。新文本框默认靠右、占所在区域 40% 宽。
- 桌面上悬停文本框，拖动框上方的拖动柄可以移动它；放到所在区域的左半边或右半边，文本框就改为靠左或靠右。旁边的两个按钮也可以直接切换。
- 拖动文本框内侧边缘调整宽度（20%–80%）；焦点在边缘时也可以用左右方向键调整。
- 列表、表格、代码块等不会环绕文本框，而是从文本框下方开始。手机宽度下文本框不浮动，按顺序独占一行。
- 文本框是带布局信息的高亮块：块操作里可在高亮块和文本框之间互转，调色按钮同样可用。1.6.0 及更早版本会把它显示为普通高亮块，内容不受影响；在旧版本里编辑保存后，浮动和宽度设置会丢失。

## 正文快捷键

- Tab：没有选中文字时，在光标处插入 4 个空格；Shift+Tab 删除光标前或段首的这 4 个空格。选中文字时 Tab / Shift+Tab 仍增减整段缩进；列表、表格、代码块中的行为不变。
- Ctrl+E（macOS 为 ⌘E）居中对齐，Ctrl+L（⌘L）左对齐。富文本中的行内代码改为 Ctrl+Shift+E（⌘⇧E）。

分栏、高亮块、文本框、折叠块和带标题的代码块在 Markdown 中保留为 HTML，以保存内部结构。外部 Markdown 工具的显示效果取决于其 HTML 支持。

这些能力使用 Web、桌面端和 Android 共用的富文本编辑器；只读状态不能修改内容。
