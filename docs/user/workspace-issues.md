# 工作区议题与站内通知

议题用于工作区成员提出问题、讨论方案和记录处理结果。它独立于笔记，不会混入笔记列表，也不会修改分享页评论。

1. 切换到一个工作区，点击侧栏或快捷栏中的「议题」。
2. 点击「新建议题」，填写标题和正文。正文、回复支持 Markdown，可选择关联当前工作区内可访问的笔记。
3. 在详情页回复、编辑或删除自己的回复。关联笔记按钮可返回对应笔记。
4. 处理完成后点击「关闭议题」。关闭保留正文、回复和状态历史，也可以重新打开。
5. 点击「通知」查看其他成员创建、回复、关闭或重新打开议题的消息；点击消息会标为已读并进入对应工作区的议题。

列表提供「全部 / 进行中 / 已关闭」过滤和分页。通知中心提供全部、未读过滤和「全部标为已读」。快捷栏上的数字表示当前账号在所有仍有成员身份的工作区内的未读消息总数。

| 角色 | 查看 | 创建、回复 | 关闭、重开 | 编辑议题正文 |
| --- | --- | --- | --- | --- |
| 所有者、管理员 | 是 | 是 | 任意议题 | 任意议题 |
| 编辑者 | 是 | 是 | 任意议题 | 自己创建的议题 |
| 评论者 | 是 | 是 | 自己创建的议题 | 自己创建的议题 |
| 查看者 | 是 | 否 | 否 | 否 |

回复的编辑和删除仅限回复作者，且作者仍需拥有评论权限。系统管理员沿用项目现有的工作区管理旁路权限。

通知发给事件发生时的其他有效成员，发起人不收到自己的操作通知。离开或被移出工作区后，历史通知也不可再读取。关联笔记有自己的权限检查；议题成员身份不能绕过受限目录或笔记权限。

V1 使用站内通知，前台每 45 秒刷新，打开通知、返回窗口或操作议题后会主动刷新。它需要连接工作区服务器；原生本地离线模式没有协作议题入口。创建或回复失败会保留输入内容，不会显示虚假的提交成功。

V1 暂不包含指派、标签、@成员、订阅设置、系统推送和邮件通知。
