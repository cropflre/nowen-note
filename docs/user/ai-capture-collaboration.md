# AI 快记 / AI capture

在手机笔记列表顶部或导航栏点「AI 快记」：

1. 随手写下一点想法。
2. 点「帮我整理」，查看或修改结果。
3. 点「保存笔记」。标题自动提取，默认保存到当前可写文件夹。

只想先记下来，点「直接记下」即可，不需要调用 AI。关闭窗口后，未保存内容会保留在当前设备、账号和工作区；更换设备前请保存为笔记。生成需要先在原有 AI 设置中配置服务。

只有需要时才展开「补充资料或调整整理方式」：选择项目资料、更换整理方式或保存位置。目录选择会在当前设备记住。空账号首次保存时会创建「快速记录」文件夹。

「管理写作模板」可绑定一个 Skill 文件夹，其中笔记的标题是模板名、正文是指令。自动整理会按输入匹配标题；无匹配时使用灵感整理，也可手动更换。可复用已有个人指令与插件 Prompt Pack；Markdown / TXT 提示词可导入个人指令（最多 4000 字），更长内容可保存为 Skill 笔记（最多 64000 字）。这些模板只提供写作指令，不执行脚本。

项目资料仅来自你显式选择的目录及其子目录，最多使用 30 篇可读笔记并受长度预算限制；范围受限时会提示。加密笔记、含加密块的笔记与密码目录不会发送给 AI。生成内容是待核对的草稿，保存时附上原始想法和本次来源；请核对事实后使用。

保存失败会保留原请求，点击重试即可。保存成功表示已通过当前平台的笔记保存流程；跨设备同步状态请在笔记中查看。仅本机模式可保存原文，远端 AI 与模板需要连接账号。

## English

Open **AI capture** from the note list header or navigation. Write an idea, choose **Organize this**, review the result and choose **Save note**. The title is derived automatically and the current writable folder is used by default. **Just save it** stores the original without calling AI. A new account gets a Quick notes folder on its first save.

Optional sources, writing methods and destinations stay under **Add sources or change the writing method**. **Manage writing templates** can bind a folder whose note titles identify Skills and whose bodies provide instructions. Automatic selection matches those titles; you can override it. Existing personal instructions and plugin Prompt Packs are reused. Import Markdown/TXT prompts up to 4,000 characters, or save longer instructions as Skill notes up to 64,000 characters. Scripts are not executed.

Only explicitly chosen project folders and their descendants supply reference material, with at most 30 readable notes and a length budget. Truncation is disclosed. Encrypted notes, encrypted blocks and password folders are excluded. Review generated claims before use; saved drafts retain the original idea and source links.

Unfinished drafts and folder preferences stay on the current device, account and workspace. Failed saves retain the original request for retry. Saving uses the existing platform note path; check the note for cross-device sync status. AI must be configured using the existing settings. Device-only mode supports saving the original; remote AI and templates require a connected account.

本地实现，尚未发布；Safari、Android 真机与软键盘验收待完成。Implemented locally, unreleased; Safari, Android devices and software-keyboard acceptance remain pending.
