# 笔记模板与目录协作

模板用于重复创建相同结构的富文本或 Markdown 文档，例如 SMT 产品资料、测试记录。

## 创建后找到文档

在左侧目录搜索编码或规格，命中文档下面的子文档、子文件夹会默认展开。搜索时仍可用箭头收起、展开；单击已收起的文档会再次展开子内容。更换关键词时恢复默认展开，清空搜索后恢复原来的目录展开状态。三列布局下单击文档，中间列表会切换到其所在目录并滚动到该文档。

从目录的 `+` 菜单选择“从模板新建”后，目录会展开文档路径、选中并滚动到新文档，标题默认全选。输入名称后点击勾号或按 Enter 确认；取消重命名会保留已经创建的文档及原名称。

需要重新查找当前文档的位置时，双击右侧正文标题或顶部文档页签。目录会清除临时搜索筛选，展开并定位该文档，中间列表同步定位。

## 保存和管理

1. 在目标空间中准备一篇富文本或 Markdown 笔记，在笔记的 `...` 菜单或右键菜单中选择“保存为模板”。
2. 从左侧“模板管理”查看当前空间的模板。模板创建者、空间所有者和管理员可删除其有权管理的模板。
3. 模板保存的是当时的正文和附件快照。后续修改源笔记不会自动更新模板；删除模板不会删除已经创建的文档。

## 谁可以使用

| 保存位置 | 可使用范围 |
| --- | --- |
| 个人空间 | 仅模板创建者 |
| 工作区 | 空间成员；以及对该空间共享目录具有新建权限的协作者 |

工作区模板共用当前空间的模板库，无需额外设置“公开”。保存为工作区模板后，具有上述权限的人可以使用模板正文和附件快照；这不会授予他们访问源笔记或其他目录的权限。

仅有目录分享权限的协作者，应在获授权的目录中选择“新建 → 从模板新建”。即使界面当前显示个人空间，模板列表也会按照该目录所属的工作区加载。例如，SMT 空间的可编辑共享目录会列出 SMT 模板，新文档仍保存到所选共享目录。

只读协作者不能从模板创建文档；撤销目录权限后，也不能继续使用旧列表中的模板。目录分享不会自动授予模板保存或删除权限。侧栏“模板管理”展示当前选择的空间；仅目录协作者使用共享目录的新建入口选择模板。

## 当前范围

- 支持查看、删除模板，以及从已有笔记保存模板；暂不提供模板名称或正文的直接编辑。
- 没有按单个模板配置成员、公开链接或全站模板库的设置。
- 模板功能使用当前连接服务器的接口，原生移动端仅此设备模式不显示模板管理入口。
