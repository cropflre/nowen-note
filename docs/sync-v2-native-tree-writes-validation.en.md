# Native personal folder writes and structural conflict recovery

Personal offline folder creation is now implemented; see [current creation validation](sync-v2-native-folder-create-validation.en.md). The earlier move/conflict evidence below retains its original acceptance scope.

2026-10-11, continuing Draft [PR #831](https://github.com/cropflre/nowen-note/pull/831) on `codex/native-knowledge-tree-offline` into `release/v1.5.2`, baseline `24594972`. [Chinese evidence](sync-v2-native-tree-writes-validation.md), [previous reception batch](sync-v2-native-tree-pull-validation.en.md).

Subscribed Native clients can move, batch-move and sort ordinary owned personal folders under the root, a folder or a document. Structure, compatible notebook parent/order and Outbox commit atomically; failed queue inserts or graph validation roll back every local move. Complete cached owner ancestry without folder passwords is required. Structural rows provide no ACL proof. Unavailable authorization retains the existing online path; storage failure never starts a second remote write.

Schema 7 widens queue/conflict entity CHECKs without losing mutation identity, payloads, versions, retries or resolved history. Both rebuilds and the version change share a transaction. Push uses the existing baseParentId/baseSortOrder/baseIsDeleted CAS after complete Snapshot ACK binding. Lost ACK retries preserve mutation IDs. The server reuses its existing folder move service and updates compatible notebook order, preventing a subsequent rename from undoing document placement or sorting.

Pull and Snapshot reconciliation preserve pending positions and recognize an intermediate queued position after an ambiguous ACK. The existing Native conflict endpoint now supports both structural choices: keep-local uses the latest durable position with the latest remote tuple; keep-remote sends no new mutation. Invalid parents, cycles or unavailable access fail without discarding the conflict. Permanent remote folder tombstones persist a conflict before any cascading business deletion and hold the page cursor/ACK. An explicit remote choice can remove its local subtree projection before replaying business deletes, provided child writes/conflicts have been handled. Missing resources cannot be resurrected. Personal Snapshots retain the existing business-resource retention policy.
