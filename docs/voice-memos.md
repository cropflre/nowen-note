# 语音笔记

## 使用

在可编辑笔记的附件菜单选择「录音」，或输入 `/voice`、`/录音`。富文本和 Markdown 都支持。录音面板可以收起；暂停时间不计入录音时长。完成后会先写入本机草稿，再上传至开始录音时的笔记，并插入音频块。

录音、保存、播放和下载不依赖 AI 配置。删除音频块只移除笔记中的引用，附件仍可从文件管理找到。只读笔记、回收站和访客编辑器不提供录音入口。

## 草稿与恢复

上传失败时可以重新上传，也可以下载录音。重新打开应用后，未完成的草稿会出现在录音面板中。草稿按服务器及账号隔离；桌面本地模式不依赖后端端口。草稿保存在当前浏览器或客户端的 IndexedDB，清除应用数据会删除草稿。

录音期间切换笔记，完成后仍上传至原笔记。若原编辑器已离开，录音保留为原笔记附件；返回原笔记可重试插入或从文件管理插入。账号切换后停止录音并保留在原账号作用域中。原笔记被删除、移入回收站或权限被撤销时，上传失败但保留草稿。

当前草稿在录音停止并生成 Blob 后写入 IndexedDB；录制中的分片仍在内存里。如果应用在停止前被系统杀掉，尚未落盘的录音可能丢失。此版本不保证录制过程中的崩溃恢复。

本机存储配额不足时会保留内存录音并提示下载；在成功下载或写入草稿前不要关闭应用。

## 语音转写

在「设置 → AI → 语音转写」独立配置服务地址、密钥、模型和默认语言。服务地址填写兼容 OpenAI 的基础地址，例如 `https://example.com/v1`，服务端追加 `/audio/transcriptions`。密钥只存储在服务端，设置读取接口只返回是否已配置；留空保留密钥，勾选清除可删除。

点击音频旁的「转为文字」后，服务端校验附件的笔记读取权限，读取已有附件并发送 multipart 请求。单个转写音频上限为 25 MiB，请求超时为 120 秒。转写结果可编辑、复制或插入当前位置；失败不会删除录音。此版本语音接口面向登录用户，不向 API Token 开放。

## 格式与平台

富文本使用 `voiceMemo` 节点，Markdown 使用标准 `<audio controls src="..."></audio>`，兼容嵌套 `<source>`。预览、实时预览、分享和笔记 ZIP 导入导出均复用附件地址及资源处理；导出时音频作为独立资源保存。分享播放不启用自动播放。

正文始终以 `/api/attachments/<id>` 保存音频身份。Android Local-first 的本机文件 URL、离线 Blob 和服务端签名地址只在渲染时由附件访问桥解析；本地笔记写库及同步 Outbox 同样执行稳定化。转写优先使用 VoiceMemo 的 `attachmentId`，历史内容再从地址恢复 ID。

录音通过 `getUserMedia` 与 `MediaRecorder`，运行时选择浏览器支持的 MIME，不按平台硬编码格式。Web 需要安全上下文（HTTPS 或 localhost）。Android、iOS 和 macOS 声明麦克风用途，Electron 仅允许受信主窗口主文档请求音频权限。

## 验证

自动化覆盖 MIME 协商、暂停计时、资源释放、录音中断、草稿失败重试、账号及笔记切换、格式转换、分享清洗、ZIP 资源往返、转写 ACL 和 multipart，以及原生权限配置。

`Voice Memo CI` 在 main、release 分支及 PR 的相关变更中运行录音、草稿、转写、格式、ZIP 往返、音频持久化和 Local-first 同步回归，并执行前端构建、后端类型构建及麦克风权限契约。Local-first 回归覆盖真实笔记门面、Native Repository、Outbox、Sync V2 推送和第二台设备的音频源解析；数据库及网络使用替身，不验证真实设备的解码播放。

发布前仍需在 Windows/macOS Electron、Android 和 iOS 真机验证首次授权、拒绝后恢复、后台中断、实际录音播放及导出后重新导入播放。自动化权限配置测试不能替代真机验证。
