# v1.6.0 — AI Migration Hub（开发阶段）

新增统一导入与迁移中心：NMF v1、持久化任务、通用文件与安全 ZIP 适配、预览与登录会话审批、后台分批写入、迁移历史/报告、失败重试、暂停/取消及未改动结果的安全撤销。现有 MCP、REST 和 TypeScript SDK 共享同一任务服务，MCP 不提供批准工具。

Added a unified migration hub with NMF v1, persistent jobs, generic files and bounded streaming ZIP ingestion, preview-bound session approval, background writes, history/reports, retry/pause/cancel and guarded undo. MCP, REST and the TypeScript SDK use the same service; MCP cannot approve imports.

旧平台导入仍可使用。Notion 专属属性、思源统一接入、可续传大包、更多来源适配及第三方 AI 客户端实测按 P1/P2 推进。Web/桌面构建与自动化通过不代表 Android、NAS、安装包或真实多端验收完成。详见 [验证记录](../qa/ai-migration-hub-2026-10-29.md)。

Existing importers remain available. Notion-specific properties, Siyuan integration, resumable uploads, additional adapters and real third-party client acceptance remain P1/P2 work. Local builds and automated tests do not establish Android, NAS, packaged-app or production multi-device acceptance.
