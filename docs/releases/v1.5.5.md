# Nowen Note v1.5.5｜多端同步与桌面体验稳定性更新

**正式发布：2026-11-09。** [GitHub v1.5.5 正式 Release](https://github.com/cropflre/nowen-note/releases/tag/v1.5.5) · [官网多平台下载中心](https://nowen.cn/#/note/download)

## 双向同步与知识树

- Web / 桌面 / Android 改进在线双向同步通知及正在打开笔记的自动更新（#910），增加三端互达自动化回归。
- 并发修改同一篇笔记时保留两端正文，避免静默覆盖；实际内容冲突仍需要用户确认或处理。
- 知识树结构差异修复增加预检与操作意图验证，优化新用户欢迎及初次引导的一致性。

**边界**：实时同步需要同一服务端、账号和可用网络。不承诺弱网、断网或全部设备组合零延迟、零冲突；目录结构冲突也不能靠合并普通字段保证无损恢复。

## 桌面、编辑器和交互

- 优化首次下载进度、本机账号登录恢复与后端启动失败后的重试入口；修正 Lite 启动时的剪藏宿主加载。
- 新增统一交互动效系统，改善窄屏到宽屏的布局切换和手机端分享弹窗。
- 修复 Word 粘贴图片、Markdown 单个换行在预览与分享中的保留、文件浏览器复制公开图片链接等问题。

## 其他增强

- 增加 AI 生成内容来源标识、受个人令牌范围限制的日记 API 与鸿蒙导出。
- 改善历史数据库加密触发器兼容、二次验证限流及手动备份时间本地化。
- 进一步完善发布流程对 FFmpeg / sqlite-vec 的 SHA-256 校验、Android 签名证书校验和跨平台安装包的完整性校验。

## 升级与签名须知

1. 升级前备份数据库、附件及部署配置，确认可以恢复。**回滚客户端或 Docker 镜像不会回滚持久化数据库。**
2. **macOS GitHub 包没有 Apple Developer ID 签名和公证**，可能触发 Gatekeeper；Windows GitHub EXE 也没有代码签名。仅使用官方公开下载地址。
3. 多端同步需连接同一服务端与账号，历史版本、弱网和并发冲突仍需正确处理。
4. 完整 Workspace、个人应用 Studio 与插件扩展平台 V3 仍归 v1.6.0 规划；iOS、HarmonyOS、Microsoft Store 的上架进度独立于本次 GitHub 正式发布。

## English summary

Nowen Note v1.5.5, released November 9, 2026, improves two-way sync across web, desktop and Android, open-note updates, knowledge-tree conflict recovery, desktop startup reliability, responsive motion, Word image pasting, and Markdown line breaks. Concurrent edits are preserved instead of silently overwritten. Back up persistent data before upgrading. GitHub macOS packages are unsigned and unnotarized; direct Windows EXE packages are unsigned. Actual downloads follow the published v1.5.5 Release; Workspace, Studio and Extension Platform V3 remain v1.6.0 plans.
