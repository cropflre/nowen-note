## 阻塞项与分诊

- 关闭加密 CI 浏览器失败并对最终候选 SHA 重跑；本地同源测试代理修复已通过专项，远端尚未验证。
- 补齐最终候选 SHA 的 PostgreSQL 集成、Docker 真实跨版本数据升级、独立完整备份恢复、Windows/macOS/Linux 安装升级与 Android 核心 smoke。
- 最终发版 SHA 尚未确认；本轮本地候选提交的远端工作流证据待补。测试修复或代码变化后必须重新验收受影响范围。

本轮已处理的回归：

- 修复知识树权限中间件未解码 URL 路径参数的问题。包含 `:` 的节点 ID 导致所有者设置「禁止访问」被误拒绝；回归覆盖编码节点、访问模式、编码成员 ID 的撤权以及非管理员拒绝。
- Frontend 首轮为 3028 通过 / 24 失败（18 个失败文件，其中 2 个收集失败套件）。核实后更新连接探测夹具、原生客户端备案场景、模板 / Capacitor mock、文件路径读取、入口与拆分后的组件契约、语言文案和上传错误分类。MJML 改为验证 XML 结构与格式化幂等性，避免依赖标签换行位置。复跑为 3064 项通过。
- 桌面脚本首轮 157 通过 / 1 失败。核实入口通过 `installOptionalRuntime` 安装知识树恢复功能，更新断言并继续检查安装早于 React 渲染；复跑 158 项通过。
- Backend 首轮 314 文件通过 / 6 失败。除上述权限 bug，修复测试中的 sharesRouter 导入、Windows 文件 URL 路径、deny 已替换 allow 的旧断言和过期 My Day 日期。任务迁移碰撞测试只删除 v74–77 的修复记录并验证它们补齐，避免删除全部后续迁移记录而保留后续 schema；该测试验证碰撞修复，不替代真实旧库升级验收。复跑 320 文件退出成功，真实 PG 集成未配置而跳过的范围仍需补验。

## Draft 流程

真实环境必须保存以下验收结果，不能只用“安装成功”代替核心流程：

| 场景 | 验收内容 |
| --- | --- |
| 旧版数据与恢复 | 隔离的 v1.4.16 实例生成完整备份，升级到候选版，核对笔记数量、正文、目录、附件和任务；再恢复独立备份并重复核对，记录旧/新版本与备份文件 |
| Sync V2 | 两个候选客户端编辑与同步；断网编辑、重启、联网后内容可恢复；同时编辑产生冲突时选择本机/云端版本，确认最终内容一致 |
| 插件 | 安装、授予权限、运行、禁用与卸载；无效签名和不受信任 Registry 被拒绝；生产信任根配置通过既有发布门禁 |
| 知识树 | 创建、移动、共享、撤权、设置禁止访问、删除和恢复；所有者可管理，未授权成员不可访问，回收站恢复后归属和权限正确 |
| 加密 Beta | Web / Desktop 新建整篇、选区加密、正确/错误密码、编辑保存、离开锁定、离线恢复和冲突；检查当前数据库、同步与新备份不包含受保护正文，旧客户端无法覆盖密文 |
| 附件与编辑 | 图片、视频、文件、XLSX 打开及恢复；Markdown / 富文本切换和移动编辑后内容不丢失，局域网授权正常 |
| 安装与更新 | Windows Full / Lite、macOS 双架构、Linux 安装与旧版升级，校验签名与 updater 文件；Android 验证登录、编辑、同步、附件、返回导航和后台恢复 |

1. 审阅并提交候选修改，记录最终 SHA；在该 SHA 完成以上回归，关闭阻塞项。
2. 确认 GitHub CLI / Git / Docker 登录、发布权限、SignPath 配置和生产 Registry 公钥配置；确认脚本将创建的 tag 对应最终 SHA。
3. 在具备完整发布工具链的主机，通过现有 `scripts/release.sh` 明确传入 `-v 1.5.0 --draft --no-latest`，按脚本支持的平台目标运行。`--draft` 仍可能推送 tag、版本镜像和资产，并非只读预演；它也不会自动阻止 Docker latest 推送，所以候选验收必须显式使用 `--no-latest`。本轮未执行这些外部动作。
4. 保持 Draft，收齐同 tag 的 Windows 正式签名、macOS 双架构和 Linux 产物，验证 update metadata、大小、SHA-512 与 blockmap。任何失败继续留在 Draft。
5. 在隔离环境从旧版安装/升级并验证笔记、附件、Sync V2、插件、知识树、备份恢复和加密 Beta，再审阅最终 Release Notes。脚本会自动生成同版本 Changelog，生成后复核其范围、Beta 限制与发布日期，不能直接把所有工程提交当作用户说明。
6. 所有门槛满足后另行执行正式公开，再把经过验证的 Docker 版本镜像提升为 latest；不要让候选版提前进入稳定更新渠道。

当前公开最新版仍为 [v1.4.16](https://github.com/cropflre/nowen-note/releases/tag/v1.4.16)。README 的稳定版提示保留这个事实；v1.5.0 的示例命令是镜像完成发布验证后的目标，不表示镜像当前可用。
