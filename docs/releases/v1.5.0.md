# v1.5.0 Release Notes（草稿）

状态：RC 冻结准备中，尚未创建或公开 v1.5.0 Release。发布门槛与验证记录见 [冻结清单](./v1.5.0-rc-gate.md)。此文件用于审核发布说明，正式发版时以最终候选提交和实际产物更新。

## 重点更新

- Sync V2 与离线工作区：增量同步、离线阅读编辑、附件缓存恢复与冲突版本选择。
- 插件生态：插件市场、签名 Registry、权限和运行时策略、文章捕获、用户级 Webhook，以及微信剪藏示例。
- 知识树与内容管理：统一文档创建入口、目录范围与筛选、根目录文档和统一资源回收站。
- 附件与编辑：XLSX 预览及轻量表格导入、媒体访问与附件恢复、Markdown 格式化、列表布局和 Web 登录作用域修复。
- Windows 开发依赖安装路径兼容性修复。

## 加密笔记 Beta

Web / Desktop 可使用新建整篇加密文本笔记和选中文字加密。输入密码查看与编辑，整篇笔记自动保存，闲置或进入后台时保存后锁定。

- 移动应用暂不支持创建或解锁，移动端能力后续逐步补齐。
- 已有普通笔记整篇转换尚未开放；已有文字可使用选区加密。
- 局部编辑仍需点击保存；未保存的会话修改可能在关闭窗口后丢失。
- 仅正文受保护，标题、目录和标签仍可见；图片、附件等内容暂不支持加密。
- 选区加密不会清除历史记录、旧备份、导出或其他设备中的旧内容。
- 忘记密码无法恢复。不要把 Beta 描述为“全平台完整加密”。

使用方法见 [加密笔记说明](../user/encrypted-notes.md)。#796 的后续工程验收继续跟踪，不以所有开发里程碑完成作为此次 Beta 纳入版本的条件；数据丢失、明文泄露或兼容性破坏仍属于发布阻塞问题。

## 升级前准备

1. 在升级前生成完整备份，保留独立副本，并在隔离环境验证恢复。数据库、附件、配置和远程对象存储均需确认可恢复。
2. 先在测试环境执行 v1.4.16 → v1.5.0 升级和恢复检查，再升级生产环境。回滚镜像不等于回滚数据库。
3. 多设备部署应统一升级客户端，尤其是 Sync V2、含局部加密区域的笔记和插件运行时策略。
4. 确认 `v1.5.0` 镜像和客户端正式产物已存在且通过验证后，才使用该版本。冻结期间生产环境继续固定已发布的稳定版。

## 发布产物验收

正式公开前检查 Windows Full / Lite 的 SignPath 正式签名、macOS Intel / Apple Silicon、Linux、相应 updater metadata、SHA-512、文件大小与 blockmap。生产 Registry 信任根沿用现有 tag 发布门禁。

当前仅准备说明和本地回归，未完成全平台安装/升级验证。完整门槛、阻塞项、CI 链接及后续 Draft 流程见 [冻结清单](./v1.5.0-rc-gate.md)。
