# 飞牛 fnOS｜Nowen Note v1.5.5 更新日志修订包

> **适用**：飞牛 fnOS x86_64 NAS。应用显示版本仍为 **v1.5.5**；文件名带 `fpk-r1` 表示同版本的修订打包，不是 v1.5.6。

## 软件简介（飞牛应用中心）

**弄文笔记（Nowen Note）** 是一款开源、自托管的个人知识管理工具，可部署在飞牛 NAS 上，支持 Markdown 编辑、知识树、文件管理、任务管理、AI 辅助以及 Web / PC / Android 多端同步。笔记和附件保存在自己管理的设备中，适合建立个人知识库和管理日常任务。

## 本次 FPK 修订更新

- **修复应用内更新日志**：补齐 v1.5.4、v1.5.5 中文更新内容，精简 v1.5.3 的冗长英文开发提交。
- **同步与冲突说明**：展示 v1.5.5 的在线双向同步、知识树冲突检查与桌面恢复等更新亮点。
- **防止重复漏打包**：构建时从经审核的版本数据生成日志；版本不一致会终止构建。
- **改进飞牛应用详情**：修正旧简介中的 v1.5.4 字样，随版本生成更新内容和备份提示。

此修订主要更正发布资源与界面文案，不声称新增超出 v1.5.5 的业务能力。

## 安装与兼容

- FPK 应用版本：**1.5.5**（fnOS 第三方应用支持的标准 X.Y.Z 版本格式）。
- Docker 镜像：`cropflre/nowen-note:v1.5.5-fpk-r1`（专供本修订包，x86_64）。
- 保留原正式版 `cropflre/nowen-note:v1.5.5` 和 `nowen-note-1.5.5.fpk` 不动，避免影响其他已安装用户。
- 若 fnOS 不允许相同版本覆盖安装，请先备份数据库、附件与应用配置，再按应用中心实际支持的更新流程处理；**不要直接卸载并清空数据**。
- 网络同步需要设备在线并连接同一个服务端和账号。离线或并发写入仍可能出现需要处理的冲突。
