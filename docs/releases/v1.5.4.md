# Nowen Note v1.5.4｜AI 写作、Markdown 折叠与离线体验升级

这次更新聚焦日常写作与多端使用：长文档更容易导航，AI 修改可以先预览再确认，图片预览、附件上传和 NAS 离线使用更加稳定。

## AI 协作，先看方案再应用

- 编辑器内加入 AI 助手，结合当前笔记和选区生成修改建议，预览、确认后再应用到正文。
- 笔记本 Agent 支持按范围整理资料、生成笔记和任务草稿；应用前可逐项检查、筛选并确认。
- 支持自定义 Skills，在 AI 对话和编辑器助手中复用写作要求与处理步骤。Skills 仅提供指令，不运行脚本或额外获取权限。
- 管理员可配置共享 AI 模型并授权成员使用，API 密钥保留在服务端；同时改进自定义网关请求头、Anthropic Messages 接口和模型连接诊断。

## 长篇 Markdown，更容易阅读和编辑

- 新增章节折叠，支持标题层级、折叠栏和桌面快捷键；折叠只改变视图，不改写正文。搜索命中隐藏内容时会自动展开。
- 修复 Live 模式中打开、关闭图片预览时的闪烁，改进附件链接打开与访问授权。
- 增强 Mermaid 对流程图标签括号和独立 `//` 注释的兼容性。

## 图片与附件，交互更稳、显示更清楚

- 改进全屏图片的缩放、拖动、双指手势、横竖屏切换及多图浏览，减少拖动误关闭和手势状态残留。
- 全屏预览使用已授权的原始分辨率附件地址，避免沿用缩略图；修复图片解码前比例判断导致的显示失真。
- 附件上传后即使响应丢失，也可找回已保存文件的准确身份，减少重复上传和失效引用。
- 缩短稳定附件分享链接，增强 HEIC/HEIF 兼容预览。

## NAS 与离线使用，减少手动操作

- 桌面完整版登录 NAS 后可自动准备个人笔记和受管附件的本地副本；首次下载完成后，断网仍可继续阅读和编辑。
- 恢复连接后自动回传待同步修改，下载中断支持重试；旧版未确认写入和冲突继续保留，不通过清空队列掩盖问题。
- 加强 Android 本地优先模式下的附件下载、账号切换、离线重开和重连同步处理。

## 导入、界面与兼容性

- Word（DOCX）导入文件大小上限提高到 1 GB，保留解压和内容安全校验。
- 改进浏览器剪藏图片的 Referer 规则隔离，减少并发剪藏之间的相互影响。
- 优化移动端 AI 设置和助手面板，改善大字体下的笔记卡片显示，并新增 Microsoft Store 下载入口。
- 更新 Node.js、Electron 和 React 运行时；完善数据库版本不兼容提示、升级保护和 SDK 独立构建。

## 升级前请确认

1. **先备份，再升级。** 完整备份数据库、附件和部署配置，并保留可独立恢复的副本。回滚客户端或 Docker 镜像不会自动回滚数据库；需要降级时，应使用升级前的完整备份。
2. 桌面安装包自带运行时，无需另装 Node.js。新版 macOS 桌面包要求 **macOS 12+**；在 macOS 上独立运行源码、CLI 或 MCP 时，官方 Node 24 二进制要求 **macOS 13.5+**。
3. NAS 离线增强主要覆盖个人笔记和受管附件，不等于共享空间、独立文件管理、任务和脑图均已支持完整离线使用。首次下载仍需联网，桌面 Lite 不包含本地后端。
4. **Workspace、个人应用 Studio 和扩展平台 V3 仍属于 v1.6.0 规划，不作为本次新增交付。**

下载平台和架构请以本次 GitHub Release 的实际附件为准。Microsoft Store、TestFlight 及其他商店的审核与上架进度独立于 GitHub 和 Docker 发布。

## English summary

Nowen Note v1.5.4 adds reviewable AI editing, notebook-scoped draft workflows, reusable instruction-only Skills and administrator-managed shared model profiles. Markdown gains chapter folding with automatic search reveal. Image viewing, attachment recovery after lost upload responses, HEIF previews and NAS offline copies are improved. DOCX imports now allow files up to 1 GB, and browser clipping better isolates concurrent image requests.

Back up the database, attachments and deployment configuration before upgrading. Rolling back an app or image does not roll back persisted data. macOS desktop packages require macOS 12+; standalone source, CLI and MCP use with official Node 24 binaries requires macOS 13.5+. Workspace, Personal App Studio and Extension Platform V3 remain planned for v1.6.0. Available downloads are defined by this release's actual assets; store publication is separate.
