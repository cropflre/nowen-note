## ✨ 更新亮点

**Nowen Note v1.5.5 正式发布！** 本次重点优化多端同步、知识树冲突处理和桌面端稳定性，并带来更加统一、流畅的交互体验。

### 🔄 Web / PC / Android 双向同步
- 优化在线变更通知，正在编辑或查看的笔记可自动接收其他设备的更新（#910）。
- 改进多端并发编辑处理，保留双方正文，避免内容被静默覆盖。

### 🗂️ 知识树与多设备冲突修复
- 加强目录结构差异的修复前检查与操作确认。
- 优化多设备登录后的新手引导状态，减少重复引导和结构冲突带来的干扰。

### 🖥️ 桌面端稳定性提升
- 优化首次同步下载进度、本地账号登录恢复及失败重试。
- 修复桌面后端启动异常后的恢复流程，改善 Lite 版启动体验。

### 🎨 界面动效与编辑体验
- 引入统一交互动效设计系统，优化页面切换和界面反馈。
- 修复窗口缩放后的工作区布局、手机端分享弹窗裁切。
- 改进 Word 图片粘贴、Markdown 换行显示及文件图片链接复制。

### 🛠️ 兼容性与其他改进
- 完善 AI 生成内容标识、个人日记接口权限校验和鸿蒙导出。
- 改进历史数据库迁移、账号验证和备份时间显示。

## 📦 下载与升级

支持 **Windows、macOS、Linux、Android、飞牛 fnOS、绿联 UGOS、Docker** 及浏览器剪藏插件。

[**官网下载中心**](https://nowen.cn/#/note/download) · [**完整更新日志**](https://github.com/cropflre/nowen-note/blob/main/docs/releases/v1.5.5.md) · [**问题反馈**](https://github.com/cropflre/nowen-note/issues)

> **升级提醒：** 升级前请备份数据库、附件及部署配置。回退客户端或 Docker 镜像**不会**回滚持久化数据库。实时双向同步需要设备在线并连接同一服务端与账号，网络中断和真正的并发冲突仍可能需要用户处理。
>
> **安装包签名：** GitHub 发布的 macOS 安装包未进行 Apple Developer ID 签名或公证，可能触发 Gatekeeper 提示；Windows GitHub 直接下载 EXE 也未提供代码签名，请从官方渠道获取。
