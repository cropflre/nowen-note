# 微信文章采集

用户入口收敛为「复制或粘贴文章链接 → 确认采集 → 查看结果」。插件 ID 保持 `nowenlab.wechat-capture`，源码版本为 1.2.0，使用 `sandbox-js`，不需要官方 Node Runtime 策略、公众号 AppID/AppSecret、回调部署、扫码绑定或阅读会话参数。

## 使用

1. 安装、授权并启用「微信文章采集」。
2. 在微信中复制想保存的公众号文章链接，返回桌面应用，点击提示中的「采集」。
3. Web 默认识别页面里的粘贴事件；在「设置 → 插件 → 微信文章采集」点击「读取剪贴板 / 授权浏览器」，浏览器允许读取后，返回页面也可自动提示。不支持或拒绝剪贴板授权时仍可手动粘贴。
4. 在插件页面粘贴一篇或多篇文章链接也可直接采集，最多 20 篇。结果自动保存到个人「微信收件箱」，可查看进度、打开笔记或重试失败项。

识别只提取 `https://mp.weixin.qq.com/s/...` 或完整的 `/s?__biz=...&mid=...&idx=...` 公开文章链接；不上传剪贴板的其他文本，会移除 key、uin、pass_ticket 等会话参数。返回应用或粘贴才检查，不持续轮询剪贴板。取消不会创建采集任务，同一链接在本次登录使用期间不会重复提示。可以在插件页关闭提示，插件禁用、卸载或权限撤销后也会停止识别。

指定公众号可以通过粘贴该公众号的多篇文章链接采集。**按公众号名称搜索、自动获取全部历史文章尚未实现**，普通入口不再要求用户填写 Cookie 或阅读会话 URL，也不提供伪扫码登录。微信验证码、登录或访问限制会显示采集失败，不生成验证页笔记。

## 实现与兼容

- Host 的登录界面桥接剪贴板确认；插件不获得通用剪贴板 API。Electron IPC 只向受信主窗口返回清理后的微信文章链接，并要求窗口处于前台。
- `/api/wechat-capture` 提供状态、用户级提示偏好、批量链接提交和失败重试，拒绝 API Token，只接受登录会话。后端提交也检查公众号文章 URL、插件状态、策略与采集权限。
- 复用已有持久化采集队列、自动目标笔记本、去重、图片附件和提取流程；沙箱插件保留旧 item receipt key，更新不会丢失采集记录或笔记引用。
- 旧 `/wechat-assistant` 服务及数据保留兼容；旧消息接入和手填会话实验从产品界面移除。1.1.0 仍可手动采集，但剪贴板提示需更新插件到 1.2.0。
- 此源码版本和本地 `.nowen-plugin` 包不等同于签名插件市场发布。市场更新须走现有签名 Registry 发布流程。

## 验证

`backend/tests/wechat-simple-capture.test.ts` 覆盖免参数沙箱采集、去重、隔离、偏好、禁用与权限撤销。前端测试覆盖识别、取消、确认、失败重试和无授权降级；Electron 测试覆盖仅返回公开文章链接和边界。真实微信可用性仍受上游访问限制，需要在实际用户环境验收。
