# 扩展中心使用教程（1.6.0）

本教程面向使用者和管理员，介绍 1.6.0 的扩展中心、工作台、编辑器扩展动作和创建应用。实现细节与接口见文末的“相关文档”。

适用平台为 Web 和桌面客户端。Android、iOS 原生 App 不显示扩展中心，见[平台支持](#平台支持)。

## 打开扩展中心

点击左侧导航的「应用」图标进入扩展中心。顶部有五个页面：

| 页面 | 用途 |
| --- | --- |
| 我的应用 | 打开已安装的应用页面和自己创建的应用 |
| 发现插件 | 搜索、筛选和安装插件 |
| 我的插件 | 查看状态、权限和来源，停用、更新或卸载 |
| 工作台 | 用卡片拼出自己的首页 |
| 创建应用 | 从模板或一句话描述创建个人应用 |

## 安装插件（管理员）

1. 在「发现插件」中搜索或按分类筛选，点「详情」查看用途、来源、版本、所需权限和兼容平台。
2. 点「安装」，阅读第三方代码与权限说明后点「继续安装」。
3. 新插件先处于隔离状态。点「审核并启用」，逐项确认权限后点「确认权限并启用」。

注意：

- 来自 Registry 的插件会先校验签名和文件哈希，校验失败不会安装。
- 普通成员看到的是「需管理员安装」，无法自行安装、授权或启用。服务器同样会拒绝这些请求，不能绕过界面完成。
- 有新版本时，卡片上显示「可更新到 x.y.z」。如果新版本扩大了权限或兼容范围，需要再次确认；更新后运行失败会自动回滚到原版本。
- 「我的插件 → 高级」保留原来的插件管理界面，可以上传 `.nowen-plugin` 文件安装。

## 管理已安装的插件

在「我的插件」中可以：

- **停用**：插件的菜单、应用页面和工作台卡片立即消失，数据保留。重新启用后恢复。
- **卸载**：
  - 带有应用数据的插件可以选「卸载并保留数据」，之后重新安装时数据还在；
  - 选「删除数据并卸载」会删除所有用户和工作区中该插件的数据，无法撤销。
- **审核新增权限**：权限变化后，插件在你确认前不会使用新权限。

## 我的应用

- **插件提供的应用页面**：在隔离的框架中运行，可以「固定到侧栏」。这类页面拿不到你的登录凭据，也读不到宿主页面；插件被停用或权限变化时，页面会立即关闭。
- **自己创建的个人应用**：见[创建应用](#创建应用)。

## 工作台

1. 点「编辑布局」进入编辑状态。
2. 调整卡片：
   - 桌面端可以拖动卡片；也可以聚焦卡片的拖动把手，用方向键移动；
   - 可以调整卡片大小，或用「隐藏卡片」「移除卡片」；
   - 点「添加卡片」可以从三组里选：内置卡片（快速记录、今日待办、最近笔记、任务概览、日记日历、收藏笔记）、我的应用、插件卡片。
3. 改错了可以点「撤销」。点「完成编辑」保存。

说明：

- 每台设备最多 5 套布局，每套最多 12 张卡片。
- 布局只保存在当前设备，并按服务器、账号、工作区和屏幕尺寸分别保存，不会跨设备同步。
- 插件被停用、卸载或个人应用被删除后，对应卡片变成休眠占位，不显示任何旧内容；插件重新启用后卡片恢复。编辑布局时可以移除休眠卡片。

## 编辑器扩展动作

管理员需要先在服务器上设置 `NOWEN_EDITOR_ACTIONS=1`，再安装带编辑器动作的插件（例如示例插件 Text Tools、AI 写作助手）。这个开关默认关闭。

开启后，富文本和 Markdown 两种编辑器里都有三个入口：

- **斜杠菜单**：输入 `/` 和关键字，例如 `/meeting`。
- **选区菜单**：选中文字后点扩展菜单按钮。
- **工具栏**：编辑器工具栏中的扩展菜单。窄屏下在「更多」里。

运行动作时：

- **只发送选中的文字**：插件拿不到整篇笔记、其他笔记或你的凭据。
- **预览**：有的动作会先显示预览，你可以选「替换选区」「插入到正文」「复制结果」或「取消」。
- **写入与撤销**：结果通过编辑器的一次修改写入，可以用 `Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 重做。
- **改动保护**：动作运行期间，如果你改了选中的文字，会提示「文档已变化，结果没有写入」，不会覆盖你的新内容；你可以复制结果或重新运行。
- **不可用的笔记**：锁定、加密、受密码保护或只读的笔记不显示扩展菜单，服务器也会拒绝执行。
- **AI 动作**：使用你在设置中配置的模型，生成的内容带 AI 来源标记。

## 创建应用

在「创建应用」中有两种方式：

- **选模板**：项目进度、阅读记录、习惯追踪、会议纪要、旅行清单、日常待办、个人资料库。
- **用一句话描述需求**：由 AI 生成草稿。没有配置 AI 模型时，页面会提示「打开设置」，并引导你改用模板。

使用说明：

- 草稿要点「保存应用」后才会创建。之后可以继续编辑字段，也可以查看历史版本并恢复。
- 在应用页点「添加到工作台」，就会在当前设备的工作台加一张卡片。
- 字段目前只有文本和勾选两种。每个应用最多 8 个字段、100 条记录，每个账号最多 32 个应用。
- 不会运行任何 AI 生成的代码。

## 平台支持

| 功能 | Web | 桌面客户端 | Android / iOS |
| --- | --- | --- | --- |
| 扩展中心、工作台、创建应用 | 支持 | 支持 | 不显示入口 |
| 插件应用页面、插件卡片 | 支持 | 支持（1.6.0 起） | 不支持 |
| 编辑器扩展动作 | 支持（需开启） | 支持（需开启） | 不显示 |

在原生 App 中直接打开扩展中心的链接，只会看到“此应用不可用……或当前客户端不支持”的说明，不会尝试运行插件。

## 常见问题

**看不到「应用」入口？**
原生 App 不提供扩展中心。在 Web 或桌面端请确认服务器可以连接。

**安装按钮显示「需管理员安装」？**
只有管理员可以安装和授权插件，请联系管理员。

**工作台里某张卡片变成了休眠占位？**
对应插件被停用、卸载或权限有变化，或者个人应用已被删除。请管理员在「我的插件」重新启用或审核权限。

**编辑器里没有扩展菜单？**
可能有以下原因：
- 服务器没有开启 `NOWEN_EDITOR_ACTIONS`；
- 当前笔记是只读、锁定或加密的；
- 插件未启用，或缺少已授权的权限。

**AI 生成不可用？**
在「设置」中配置 AI 模型地址和模型名；使用云端服务时还需要填写密钥。
