## 已复现与修正

1. 首次中文用例拿到真实提案，但将“5 分钟”与“5分钟”视为不同内容。事实校验改为允许数字/空格排版，并增加本地队列与网络恢复语义检查；链接、实际写入和重启后精确一致性校验保留。
2. 百炼官方域名的 Agent 请求使用 `enable_thinking: false`；DeepSeek 原生接口保留其自身参数，其他接口不改变。没有根据模型名称推断工具能力，仍要求结构化工具调用。
3. 新失败用例证明：超时/取消时，尚未结束的响应体与迟迟不返回的取消清理不能让运行继续等待。单次 45 秒预算改由显式定时器持有，并在读取阶段传播取消；取消、错误和成功均清理监听器与定时器。
4. 新失败用例证明：完整 SSE 终止帧到达后，不应继续等待底层连接关闭。收到 `[DONE]` 后结束解析并发起清理；缺少结束标记或不完整工具参数仍拒绝。

前几轮 P2 未在 120 秒内进入审批，均记录失败，没有计为通过。定位确认检索已经返回两篇来源，等待发生于第二次模型回复。独立重放曾接近六分钟才返回有效工具结果；不把这个观测单独归因为服务端或网络。最终场景明确要求一句话摘要、150 字内的新笔记，保留全部四项技术事实；未放宽 45 秒单次请求、120 秒工作流预算或审批规则。
