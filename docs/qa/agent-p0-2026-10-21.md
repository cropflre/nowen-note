## 场景与安全证据

| 场景 | 已验证范围 / 限制 |
| --- | --- |
| 读取与提案 | 两轮真实 Runtime 调用，当前未保存快照进入上下文；工具 ID、并行参数分片和中文 UTF-8 SSE 拼接；普通 Markdown 文本不能冒充工具 |
| 拒绝与审批 | 拒绝不写正文；缺失/重复凭证拒绝；审批响应丢失不重放；前端在请求前后都重验快照；过期版本和同版本正文变更均拒绝 |
| 编辑器与持久化 | 两种编辑器真实应用、原生 Undo/Redo、保留后续输入、刷新后正文匹配；富文本 marks/link/block ID/attachment 有精确结构测试，Markdown 链接和附件有保留约束 |
| 停止与恢复 | 终止上游且不产生后续提案；关闭面板后的迟到审批不能改旧笔记；后端运行实例重建将未完成审批中断；完成后 DB 关闭重开仍保留正文 |
| 保存与 Outbox | 使用已有 notes 保存路由捕获 Outbox，DB 关闭重开后意图保持；既有离线队列、收据和同步安全测试通过；没有清空或伪造 Outbox ACK |
| 读取一致性 | 第二个浏览器上下文可读取同一服务端已保存结果；**不等同于两个独立 Sync V2 设备收敛** |
| ACL 与隐私 | 跨用户、工作区 viewer、密码目录、锁定资源、restricted PAT、关闭 AI 开关均拒绝；撤销 tokenVersion 阻止后续工具；日志表不含测试正文、密钥或明文审批凭证 |
| 注入与非法输出 | 非白名单工具、非法参数、重复循环拒绝；模型 HTML 在 Diff 中为转义文本；不暴露任意 SQL、Shell、网络或插件动作 |
| 超时 | 用短时钟替代 45 秒请求定时器，验证请求超时为 `MODEL_TIMEOUT`，没有提案且只请求一次；生产阈值仍为 45 秒 |
| 移动布局 | Chromium 390px 宽度布局无水平溢出；不等同于 Android 真机、软键盘或客户端验收 |

本轮发现并修复两类实际问题：

1. Yjs 会在时间窗口内合并版本，不能只用 `version > expectedVersion` 判定持久化，也不能只用版本号判定审批未过期。新增服务端正文摘要校验；保存收据核对精确正文、已消费审批及不倒退的版本，只允许持久化新增系统块 ID。先增加失败用例，再修复并通过真实两种编辑器 E2E。
2. 45 秒上游请求超时原先落入普通请求失败。新增用例复现 `MODEL_REQUEST_FAILED`，修复为 `MODEL_TIMEOUT` 后回归通过。
