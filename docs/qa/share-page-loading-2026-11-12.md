# 分享页低带宽加载验证

## 问题与改动

简单文字分享会启动主应用、工作台桥接与完整编辑器；格式判断、缩进、照片预览和时间工具还会间接引入转换器、编辑器 schema、代码高亮及整套翻译目录。

- Web `/share/:token` 使用独立入口，保留反代路径和 base64url token 支持。Native / Electron 继续走原入口。
- 访客开始编辑时才加载编辑器；加载完成前先安装原有保护逻辑、翻译和图片 schema。
- 代码高亮在实际出现富文本代码块后加载，失败时保留转义后的代码文字；图片灯箱点击后加载。
- 格式判断、缩进值和照片预览使用不依赖完整编辑器/预览分发器的模块；时间工具使用已存在的 i18next 实例。
- 保留管理员关闭 Web UI 的检查、分享密码和现有权限接口。

## 构建资源对比

本地 Chromium 冷加载同一份无密码、仅查看、几个文字的 Markdown 分享；API 使用测试数据，未使用私人笔记。无图片、Banner、自定义字体。统计实际请求的 JS/CSS，包含入口动态加载的依赖，不包含 HTML、API、响应头。

| 指标 | 修改前 | 修改后 | 减少 |
| --- | ---: | ---: | ---: |
| JS/CSS 原始字节 | 6,577,485 | 1,575,783 | 76.0% |
| 同批资源 gzip 估算字节 | 1,908,340 | 445,471 | 76.7% |

gzip 数值由资源内容压缩计算，需部署实际启用压缩后才代表接近的传输量；不是生产服务器测速。3 Mbps 下仅这些 gzip 字节的理想传输耗时约从 5.1 秒降到 1.2 秒，不含延迟、请求处理和浏览器渲染。

浏览器回归为小文字分享设置 1.8 MB 原始资源 / 500 KB gzip 估算预算，并拒绝加载工作台、编辑器、Core Runtime、高亮或灯箱 chunk。运行结果附件中保留逐文件资源报告。
