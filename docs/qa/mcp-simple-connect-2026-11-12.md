# AI 助手简易连接验收

## 用户流程

「设置 → 连接 AI 助手」只显示一个助手下拉框、笔记本和「连接」。
下拉框分为「国内助手 / 其他助手」：新增 WorkBuddy、CodeBuddy Code、TRAE 国内版、Qoder、Kimi Code、Qwen Code，保留 Claude Code、Cursor、Codex。
Cursor、TRAE 国内版提供一个安装按钮；其余助手提供一个复制按钮，内容已包含相应客户端的接入配置。
页面不展示协议、密钥输入、JSON、写入开关或高级管理折叠项。有效期使用一个可选天数输入框，留空为永久；拒绝零、负数、小数及超出日期范围的天数。
已有授权直接按助手名称显示，提供「断开」。开发者访问令牌保留在账号安全中。

## 实现范围

- `McpConnectionPanel` 仅检查服务状态并承载简易连接，保留迁移用途的既有分支。
- `McpQuickConnect` 完成选择、准备、接入和断开，失败不伪装为成功，检测重试不重复创建授权。
- `mcpConnections` 复用既有服务配置和 Token API，默认全选当前全部可授权笔记本，也可逐个调整；创建默认永久、可自定义天数的 restricted、精确到勾选笔记本的笔记增删改查授权。仅授予 `notes:read`、`notebooks:read`、`notes:write`，逐本按 `canWrite` 授予 write/read，取消子笔记本不会因父本已选而保留访问。
- 管理员点击连接时开启服务与写入；普通用户不能自行开启。已有只读授权不自动扩权，需断开后重新连接。后续新增笔记本也需重新连接时选中。
- 删除沿用默认预览、明确确认、版本检查及回收站软删除；不开放永久删除或笔记本结构写权限。
- 明文只保留在当前组件会话；不写入浏览器存储或离线队列。DCC-006 覆盖账号/服务器切换后的迟到凭据拒绝。
- 配置合并说明要求保留其他服务，出现同名不同地址时先询问，不能把准备好接入材料说成外部客户端已接入。

## UI 约束

复用现有 `--color-surface`、`--color-bg`、`--color-border`、`--color-active`、`--color-accent-primary` 和文字语义变量，未增加全局主题规则。
深浅主题继承现有变量；助手选择使用带分组的原生下拉框，笔记本列表限高滚动，控件最小高度 44px，保留标签、原生键盘操作和可见焦点。
没有新增装饰动画；加载图标在 reduced-motion 下停止旋转。没有加入桌面专属 hover 操作。

## 验证边界

本轮未执行浏览器目视验收或实际安装到外部客户端；主题/移动端布局为实现约束与组件验证，不能视作截图验收。
客户端材料参照[架构文档所列官方来源](../architecture/docker-embedded-mcp.md#客户端材料)适配，包括 WorkBuddy 的 `streamableHttp`、CodeBuddy/Qoder 的 `http`、TRAE/Kimi Code 的 `url`、Qwen Code 的 `httpUrl` 差异。
国内客户端的配置字段、用户级配置位置、TRAE 国内版安装链接均已完成新增回归检查，不能用这些检查替代真实客户端安装验收。
普通豆包、DeepSeek、Kimi 网页聊天不应被泛称为可直接接入，Kimi Code 等 Agent 产品需与同名聊天产品区分。
提交与分支状态以 Git 记录为准；本验收记录不代表已发布正式镜像。
