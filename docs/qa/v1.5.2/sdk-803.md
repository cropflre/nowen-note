## 修复范围

- 默认 fetch 绑定浏览器全局对象；公开登录、两步验证、Token 设置与读取。
- 核心客户端和 `client.attachments` 共用认证状态，外部 Token 清除旧自动登录凭据。
- 账号切换先清除旧 Token；待完成 2FA 时业务调用返回带挑战信息的 `TwoFactorRequiredError`。
- 迟到登录/2FA 响应不能覆盖新 Token，旧请求的 401 不能以新身份自动重试写入。
- 附件关联读取后切账号会拒绝写入；同账号正常 Token 更新仍可继续关联。
- 日记时间线、媒体及 Token 验证类型对齐服务端；相关类型由公开入口导出。

这涉及 DCC-006 的身份隔离边界，未修改服务端数据库事务、Outbox、同步游标、删除或恢复流程。SDK 身份回归位于 `packages/nowen-sdk/tests/auth.test.mjs`；现有 DCC 矩阵执行器只覆盖前后端测试，不把 SDK 回归冒充为矩阵新增覆盖。
