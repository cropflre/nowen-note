## 复测命令

在 `backend` 目录执行，复用当前 Electron ABI 130，不重新构建共享原生依赖：

```sh
ELECTRON_RUN_AS_NODE=1 ../node_modules/electron/dist/Electron.app/Contents/MacOS/Electron \
  --import tsx --import ./tests/setup-db-isolation.ts --test \
  tests/agent-workflow.test.ts tests/agent.test.ts tests/task-composer.test.ts \
  tests/user-ai-settings-isolation.test.ts tests/migration-task-version-compatibility.test.ts \
  tests/sync-v2-outbox-capture.test.ts tests/ai-context.test.ts tests/ai-collaboration.test.ts
npm run build:tsc
npm run build
```

在 `frontend` 目录执行：

```sh
npm run build
npm run test:run -- src/components/agent/__tests__ src/lib/__tests__/taskComposerApi.test.ts
```

在仓库根目录执行：

```sh
./frontend/node_modules/.bin/playwright test --config frontend/playwright.agent.config.ts \
  --output /tmp/nowen-agent-p1-browser
NOWEN_AGENT_ELECTRON=1 ./frontend/node_modules/.bin/playwright test \
  --config frontend/playwright.agent.config.ts --grep 'notebook Agent' \
  --output /tmp/nowen-agent-p1-electron
node scripts/data-consistency-contract.mjs --verify
git diff --check
```

PostgreSQL 复测需要独立测试数据库，通过 `TEST_PG_DATABASE_URL` 指向该库，然后运行 `node --import tsx --test tests/agent-postgres.test.ts`；不得指向生产库。本轮日志位于 `/tmp/nowen-agent-p1-final-backend.log`、`/tmp/nowen-agent-p1-build-frontend.log`、`/tmp/nowen-agent-p1-web.log`、`/tmp/nowen-agent-p1-electron.log` 和 `/tmp/nowen-agent-p1-postgres.log`。临时路径可被系统清理，应按上述命令重新生成证据。
