# Phase 1 Migration Hub 浏览器检查

日期：2026-10-29。浏览器：Chromium 153.0.8010.12。视口：320×900、1280×900，分别检查浅色和深色主题。

使用真实 `MigrationHub`、`MigrationReviewItems`、现有语义主题 Token 与前端上传 helper；API 由 Playwright 拦截并提供合成任务/文件，不连接真实账号，不访问用户资料。这是组件浏览器交互和布局证据，不代表生产服务、Android/Electron 安装包或真实来源包已验收。

四组均通过：

- body 实测宽度等于对应 320/1280 视口宽度，没有水平溢出，浏览器 pageerror 为 0。
- 未处理的来源变更项即使已勾选确认，仍不能批准。
- 逐项选择“导入新副本”后调用决策接口，预览摘要变化、确认勾选清除；重新勾选后才启用批准按钮。
- 从历史中的待准备任务点击“继续上传文件”，重新选择合成 ZIP。
- 服务端返回首个 4MiB 分块已确认，前端只上传偏移 `4194304` 和 `8388608`，没有重传偏移 0，也没有新建任务。
- 上传阶段显示真实进度（截图为 99%），随后等待服务端完成上传/扫描并重新进入预览；未自动批准导入。

截图均为 full-page。逐项列表本身保留产品设置的内部滚动，不为截图改变组件布局。测试壳仅把全局 App 固定高度改为普通页面滚动，以呈现完整组件；没有改动产品源码。一次性 HTML/TSX 壳已清理，独立 Vite QA 进程已停止。
