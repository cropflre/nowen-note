提交 `7ed2764947ac3bfb0d1948d53ca7103c4da3d95d` 增加共用的配置检查：远程服务需要有效接口、模型和非空凭据；Ollama、LM Studio 继续允许无密钥。P0/P1/P2 创建运行前即检查，模型适配器在每轮请求前再次检查。新用户返回 `400 AI_NOT_CONFIGURED`，不创建 run，也不发送正文；运行中移除凭据会阻止下一轮携带上下文的请求。

新增两个回归覆盖未配置用户的编辑器/笔记本入口、零请求/零 run、两种本地免密模式和运行中清除凭据。同步场景的受控远程模型 fixture 补充合成测试密钥，未放宽保存、丢失 ACK 或第二 SQLite 副本收敛断言。

## 环境与准确边界

使用 `git archive` 导出固定提交，不挂载用户数据库或 macOS 的 node_modules。完整 CI 镜像拉取遇到仓库连接/缓存问题，改用已缓存的 Debian 13 arm64 基础镜像，在一次性容器内加入 x64 运行库和从 Node.js 官方下载、按官方 SHA-256 核验的 `node-v22.23.4-linux-x64`。实际执行为 Linux / x64 / Node 22.23.4 / ABI 127，通过 Docker Desktop 跨架构执行。

这是额外的 Linux Node 22 验证，不是 GitHub Ubuntu amd64 runner，也不是原生 amd64 主机或完整 Linux 浏览器验收。macOS/Electron 原有 ABI 130 依赖没有重建或污染。临时 Linux 容器及其准备镜像在验收后删除，原有 PostgreSQL 镜像和其他服务保留。
