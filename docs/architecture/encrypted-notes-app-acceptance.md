# Encrypted Notes：完整桌面工作台与账号验收

2026-10-02，macOS arm64 / Electron 33：5 项产品链路验收通过；加密目录 97 项和原有 Electron 21 项回归通过，前端生产构建与类型检查通过。各套件有复用，不合并为独立测试总数。

## 发现并修复的缺口

完整工作台的 Markdown 默认可以使用 Live / Yjs。新增加密区域后，CodeMirror 已写入密文，但 update listener 仅在非协作模式调度保存；Yjs 服务又按设计拒绝含加密区域的更新，导致区域停留在编辑器，无法落库。

现在含保留加密标记的文档即使仍处于协作切换期间，也调度原有正文保存。已有 `emitSave` 使用密文 PUT，工作台收到本地快照后停用该笔记的 Yjs。普通协作正文仍沿用原通道；没有改变密文协议或服务端拒绝规则。新增测试在完整工作台复现旧代码不落库，再确认修复后自动保存、注销和重新解锁均能恢复原区域。

## 验收覆盖

- 整篇 Markdown：从知识树菜单创建、解锁、手动保存、未保存草稿、原生隐藏锁定、退出登录、密码重新登录、恢复服务器原密文。未保存草稿不跨登录恢复。
- 整篇基础富文本：同一真实创建/保存路径，原生后台草稿锁定后通过“登录过的账号”切换到另一账号；另一账号无法看到或经 API 读取原笔记，切回后重新输入加密口令恢复已保存正文。
- 局部 Markdown / 富文本：通过知识树创建普通文档，使用完整 EditorPane/编辑器工具栏新增加密区域，自动保存到真实 notes API；再次解锁后输入未写回内容，由另一个隐藏窗口修改共享登录存储产生真实 storage 登出广播。原窗口的临时编辑器和弹窗随账号退出销毁，重新登录和解锁只恢复之前已保存的内容。Markdown 编辑使用源码入口；预览卡片的解锁仍按原设计只读。
- 生产 IPC：非法协议、非 API 路径、不支持的方法、非主窗口来源被拒绝；未登录的 notes 请求由真实后端返回 401。发送前移除调用方伪造的 Host / Origin / Cookie / Sec-* 头，保留普通自定义头。
- 每项结束扫描生产网络请求、SQLite 全表、数据库/WAL、临时 profile/缓存/日志文件和后端输出中的专用正文/加密口令标记；未发现标记。关闭进程并删除临时目录。

## 隔离与复验

测试启动未经替换的 `electron/main-bootstrap.js`、生产 preload、原生 HTTP IPC 和完整 `frontend/dist/index.html`。独立后端导入 `index.hardened.ts`，保留真实 JWT/session、ACL、notes、知识树和 WebSocket 路由，不注入固定用户头。测试账号通过真实注册 API 建立，初次登录和注销使用工作台 UI；切换目标账号的有效历史 token 通过真实安全存储 IPC 准备，不模拟该 IPC。

每项使用 `nowen-encrypted-app-*` 临时目录及随机端口；后端 cwd、数据库、附件和备份目录全部隔离。夹具只把该进程的服务监听限制到 loopback，关闭自动备份和 mDNS 发布；桌面 session 阻止访问测试服务器以外的 HTTP(S) 地址。观察器记录请求和发送头，不替换生产 IPC 或认证处理器。页面安全参数与生产 CSP 保持原样。

需要仓库根目录、前端和后端依赖，以及图形桌面：

```sh
npm run rebuild:native
cd frontend
npm run test:encrypted-notes:app
```

命令重新构建生产前端，再运行完整工作台测试；后端通过 Electron-as-Node 使用相同 SQLite ABI。不要同时操作其他图形验收窗口，原生失焦会按设计触发自动锁定。
