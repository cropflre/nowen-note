# Native personal tree structure reception and recovery

Historical reception batch; subsequent folder writes and structural conflict evidence are recorded in [the next batch](sync-v2-native-tree-writes-validation.en.md).

2026-10-11, third reliability batch on `codex/native-knowledge-tree-offline`, continuing Draft PR #831 into `release/v1.5.2`. Baseline: `1b5b0c79`. [Chinese evidence](sync-v2-native-tree-pull-validation.md).

Native previously rejected tree entities and could only project legacy notebook parents. The engine now negotiates the existing complete entity set through `/plan`, with a stable device ID, rebuilds a paginated personal Snapshot, then receives structural changes through the existing Pull path. Workspace subscriptions remain legacy. A fresh profile can use an old server; a persisted or pending tree subscription never silently downgrades.

Schema 6 adds structural metadata without widening the locally writable Outbox registry. Snapshot replaces only remote tree metadata. Final-graph validation checks ownership, scope, resource identity/dependencies, types, ordering, parents and cycles. Invalid incremental structure rolls back business and tree changes together, before ACK. Bootstrap business pages retain their existing separate transactions; the complete graph and pending subscription intent commit together before the first ACK. An ambiguous ACK forces baseline replay after restart. Migration failure rolls back without advancing the schema version.

Actual Android acceptance found two additional defects. REST tree writes committed without waking the Native engine; successful committed structural Feed changes now reuse metadata-only `sync.changed` notices. Moving a folder back under a root document failed with `NOTEBOOK_PARENT_NOT_FOUND`; the root-document wrapper now reuses creation's temporary container activation/hiding transaction, retaining permissions and scope checks.

Final local validation: 308 backend tests and 243 frontend tests across 32 files passed, zero skips. Both production builds and TypeScript checks passed. Lint found 1447 historical errors and zero new errors. The contract gate verified 12 invariants, 82 references, 8 backend files and 18 frontend files. Full Voice CI frontend coverage includes the repaired getBaseUrl fixture. Earlier backend startup failures were caused by running from the repository root; the final complete run used the required backend working directory.
