# 思维导图模块入门

> 用节点式思维导图整理思路、梳理知识结构。

---

## 思维导图是什么？

思维导图是一种将想法以树状结构展示的工具。nowen-note 内置了思维导图编辑器，你可以直接在应用中创建和编辑思维导图，也可以从笔记一键生成。

---

## 创建思维导图

### 方法一：从导航栏进入

1. 点击左侧导航栏的「思维导图」图标
2. 点击「新建思维导图」
3. 在编辑器中开始添加节点

[截图：思维导图编辑器界面]

### 方法二：从笔记生成

1. 打开一篇笔记
2. 点击编辑器工具栏的 🤖 AI 图标
3. 选择「生成思维导图」
4. AI 会根据笔记内容自动生成思维导图

[截图：从笔记生成思维导图]

---

## 在笔记中插入思维导图

1. 打开一篇可编辑的富文本或 Markdown 笔记，把光标放在希望插入的位置。
2. 点击富文本或 Markdown 编辑工具栏中的「插入原生思维导图」图标；窄屏界面可先展开工具栏的「更多」。富文本也可输入 `/思维导图`。
3. 选择当前笔记所属空间里已有的导图，或输入名称后点击「新建并插入」。

插入的是对原生导图的引用，不是复制一份导图。刷新笔记后仍可预览；修改原导图后，重新打开笔记会看到更新。你可以在嵌入卡片中缩放、展开或打开原生编辑器；有导图编辑权限时还可以在文档内编辑。删除笔记中的嵌入块不会删除原导图。若原导图已删除或当前账号无权访问，卡片会显示不可用提示，不会绕过权限展示内容。

引用代码由应用自动生成，普通用户无需查找导图 ID 或手写语法。工作区笔记只会列出同一工作区的导图，新建导图也会保存到该工作区。

两种编辑器的脑图工具栏图标都会打开同一个原生导图选择器。若需要一段独立的 Mermaid 图表代码，请在富文本中输入 `/Mermaid 脑图` 并选择「Mermaid 脑图（代码块）」；它不会关联原生导图。选中已有导图嵌入块时再次插入，新内容会放在该块后面，不会悄悄覆盖原引用。

## 思维导图操作

### 基础操作

| 操作 | 方法 |
|---|---|
| 添加子节点 | 选中节点 → Tab 键 |
| 添加同级节点 | 选中节点 → Enter 键 |
| 编辑节点文字 | 双击节点 |
| 删除节点 | 选中节点 → Delete 键 |
| 拖拽移动节点 | 按住节点拖动 |

### 编辑器工具栏

- **撤销/重做**：左上角按钮
- **缩放**：鼠标滚轮或工具栏按钮
- **全屏**：工具栏全屏按钮
- **导出**：导出为 PNG 图片

---

## 思维导图保存

思维导图和笔记一样，编辑后会自动保存。你可以在「思维导图」列表中查看所有创建的思维导图。
