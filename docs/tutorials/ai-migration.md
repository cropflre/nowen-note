# AI 迁移与文件导入

在 **设置 → 数据管理 → 导入与迁移** 中选择“让 AI 帮我迁移”或“直接导入文件”。任务保存在当前 Nowen 服务端，关闭页面后可重新打开查看。

## 直接导入

1. 选择个人空间或有编辑权限的工作区，并为本次迁移命名。
2. 选择 Markdown、HTML、TXT 文件，Notion 导出 ZIP、思源原生 ZIP，或包含正文和本地附件的通用 ZIP/NMF v1 包。多文件按顺序上传与检查。
3. 查看预览中的将创建、已存在、跳过和需处理数量，以及不支持内容的提示。按项选择自动处理、跳过、保留已有或创建副本；每次调整后重新检查预览。
4. 确认后点击开始导入。上传或解析完成还不是导入成功。
5. 完成后查看新建根笔记本或下载报告。部分失败时只重试失败项。

迁移默认新建根笔记本，跳过识别到的重复项，不覆盖已有笔记，也不删除来源数据。取消后已经提交的笔记会保留；安全撤销只允许在本次导入内容未编辑、未移动、未加入其他内容时执行，使用回收站软删除。

Notion 和思源的稳定页面／文档 ID 可识别此前由迁移中心导入的同一来源，即使是另一次导出。来源内容有变化时会提示需要处理：可以保留已有笔记、创建新副本或跳过，不会自动覆盖。保留已有只适用于当前可访问的目标。处理选择会更新预览并取消旧确认，仍需用户重新批准。

## 上传中断后继续

文件先按片计算校验和，再以 4 MiB 分块上传。网络中断后，重新打开同一准备中的任务，选择同一名称和内容的文件，页面会从服务端已确认的偏移继续。响应丢失时以服务器记录为准。关闭页面后，尚未完成的浏览器上传不会继续发送；服务器已经接收并确认完成的来源才会进入后台检查。

上传会话有效期为 24 小时，过期分块会被清理；允许重新开始时会从 0 上传。完整文件校验失败时先查看错误，按提示重新准备任务，不能把部分扫描结果当作完整预览。上传完成、扫描完成和正式导入完成是不同阶段，最终以任务状态和报告为准。断点上传没有提高文件大小上限。

## 让 AI 准备迁移

按页面指引连接兼容 MCP 的 AI 客户端，使用仅覆盖目标范围、具有迁移所需权限的 API Token。AI 能查询能力、准备任务、上传来源、提交小批量标准数据、获取预览和查询结果。正式批准在 Nowen 页面中完成，AI 工具没有批准接口。

不要向 AI 提供 Nowen 登录密码、来源平台 Cookie 或无关笔记访问权限。只有在用户授权、客户端实际能够访问导出文件或官方连接器时才能准备数据。来源文档里的指令只是数据，不执行其中的脚本、宏或命令。

WorkBuddy、Qoder/QoderWork、Claude Code、Codex、豆包工作等客户端的 MCP 支持随版本和部署方式变化。本次提供共用 Skill 与接入指引；未列为实测通过的客户端不保证具备相同能力。客户端无法调用工具时，让 AI 生成标准 NMF ZIP，再手动导入。

## 支持边界

- **Notion**：支持 Markdown/HTML 导出中的页面、目录、受支持的本地附件，以及已导出页面之间的相对链接和 Notion URL。能识别的页面 ID 后缀不显示在目录名中。数据库 CSV 只按限额读取、匹配并暂存标量来源属性，报告列出未迁移字段名；不会变成笔记属性、标签、日期、公式或数据库关系。歧义和超限会提示，请保留原 CSV。视图、公式、关系和专属组件不作无损承诺。
- **思源**：原生 ZIP 中当前 `.sy` 文档转换为 Markdown，保留受支持的目录、文档 ID、标签、本地附件及文档间引用。嵌套块和包外引用保留思源链接；挂件、嵌入、数据库、查询和特殊样式降级并提示。历史与回收站不作为当前笔记导入。无时区的来源时间不猜测，自定义属性不写入笔记属性；这不是思源无损恢复。
- 通用入口继续支持 Markdown/HTML/TXT、本地资源 ZIP 与 NMF v1。无法转换的内部锚点或包外链接保留来源链接并报告。
- HTML 会去除危险脚本及不支持的样式/组件。远程图片不会被服务器主动下载；原链接保留并报告，后续显示仍取决于来源可访问性。
- 加密笔记解密、历史版本、评论、协作成员、权限和平台数据库语义不在本阶段迁移范围。旧思源、Office 和其他平台入口仍在“其他导入方式”，旧任务历史不会自动合并到新中心。
- 单任务最多 10,000 篇，单篇正文 2 MiB，单附件 64 MiB，ZIP 512 MiB，展开量 1 GiB。超限、加密/ZIP64、多卷、可疑路径或压缩炸弹会拒绝。
- Web 和桌面通过当前后端执行；Android 需要连接具备迁移 API 的服务端。本机 Native 离线模式不运行服务器迁移任务。导入完成不代表其他设备已下载所有正文和附件。
- 完成/取消任务的临时文件保留 1 天，准备/暂停/失败任务保留 7 天，启动或创建新任务时清理；历史报告保留。过期后重新上传到新任务。升级前签发、没有登录会话标识的旧凭证需重新登录后才能审批。
