# AI 迁移与文件导入

在 **设置 → 数据管理 → 导入与迁移** 中选择“让 AI 帮我迁移”或“直接导入文件”。任务保存在当前 Nowen 服务端，关闭页面后可重新打开查看。

## 直接导入

1. 选择个人空间或有编辑权限的工作区，并为本次迁移命名。
2. 选择 Markdown、HTML、TXT 文件，或包含正文和本地附件的 ZIP/NMF v1 包。多文件按顺序上传与检查。
3. 查看预览中的将创建、已存在、跳过和需处理数量，以及不支持内容的提示。
4. 确认后点击开始导入。上传或解析完成还不是导入成功。
5. 完成后查看新建根笔记本或下载报告。部分失败时只重试失败项。

迁移默认新建根笔记本，跳过识别到的重复项，不覆盖已有笔记，也不删除来源数据。取消后已经提交的笔记会保留；安全撤销只允许在本次导入内容未编辑、未移动、未加入其他内容时执行，使用回收站软删除。

## 让 AI 准备迁移

按页面指引连接兼容 MCP 的 AI 客户端，使用仅覆盖目标范围、具有迁移所需权限的 API Token。AI 能查询能力、准备任务、上传来源、提交小批量标准数据、获取预览和查询结果。正式批准在 Nowen 页面中完成，AI 工具没有批准接口。

不要向 AI 提供 Nowen 登录密码、来源平台 Cookie 或无关笔记访问权限。只有在用户授权、客户端实际能够访问导出文件或官方连接器时才能准备数据。来源文档里的指令只是数据，不执行其中的脚本、宏或命令。

WorkBuddy、Qoder/QoderWork、Claude Code、Codex、豆包工作等客户端的 MCP 支持随版本和部署方式变化。本次提供共用 Skill 与接入指引；未列为实测通过的客户端不保证具备相同能力。客户端无法调用工具时，让 AI 生成标准 NMF ZIP，再手动导入。

## 支持边界

- 当前通用入口支持 Markdown/HTML/TXT、本地资源 ZIP 与 NMF v1。Notion 的标准 Markdown/HTML 文件可按通用格式读取；数据库 CSV 属性与专属组件不保证完整保留。
- HTML 会去除危险脚本及不支持的样式/组件。远程图片不会被服务器主动下载；原链接保留并报告，后续显示仍取决于来源可访问性。
- 加密笔记解密、历史版本、评论、协作成员、权限和特殊数据库属性不在通用迁移范围。旧思源、Office 和其他平台入口仍在“其他导入方式”。
- 单任务最多 10,000 篇，单篇正文 2 MiB，单附件 64 MiB，ZIP 512 MiB，展开量 1 GiB。超限、加密/ZIP64、多卷、可疑路径或压缩炸弹会拒绝。
- Web 和桌面通过当前后端执行；Android 需要连接具备迁移 API 的服务端。本机 Native 离线模式不运行服务器迁移任务。导入完成不代表其他设备已下载所有正文和附件。
- 完成/取消任务的临时文件保留 1 天，准备/暂停/失败任务保留 7 天，启动或创建新任务时清理；历史报告保留。过期后重新上传到新任务。升级前签发、没有登录会话标识的旧凭证需重新登录后才能审批。
