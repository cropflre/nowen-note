# AI 对话归档（v1.6.0 开发版）

[English](ai-memory.en.md) · [架构与权限](../architecture/ai-memory-hub.md) · [验收记录](../qa/ai-memory-hub-2026-11-05.md)

当前实现的是原始对话归档 MVP。长期记忆、记忆确认、跨 AI 上下文插入和记忆专用 MCP 尚未开放。ChatGPT/豆包适配器经过本地页面 Fixture 验证，真实网站改版、安装版和实际账号仍需验收。

**默认开启。** 侧栏有「对话归档」入口，接口和浏览器扩展的保存都可用。不需要的服务器，管理员可在 **设置 → AI 助手 → 开启 AI 对话归档**（页面底部）中关闭：关闭后入口和接口停用（接口返回 `404 AI_MEMORY_DISABLED`），已保存的归档、来源和笔记都会保留；进行中的历史导入会停在「已中断」，重新开启后可重试；扩展里没发出的内容留在本机，重新开启后在网页上再点一次「存到 Nowen」即可继续发送。

## 保存当前网页会话

1. 装好 Nowen 浏览器扩展，在扩展里登录自己的 Nowen 服务器。没登录就点保存时，扩展会打开登录页。
2. 打开 ChatGPT `/c/<id>` 或豆包 `/chat/<id>` 的一段对话，页面右侧会出现「存到 Nowen」按钮。
3. 点一下。页面上能看到的整段对话会存进个人空间的「AI 对话」笔记本（没有会自动创建），按钮变成「已存 · 自动保存中」，之后这段对话的新消息会自动跟着存。在扩展弹窗里点「存到 Nowen」效果一样。

第一次保存时会自动创建以网站命名的来源（如「ChatGPT」），这个网站的其他对话共用它。只有点过按钮的对话会自动保存；装好扩展或打开页面本身不会读取聊天内容。鼠标移到按钮上可以「打开笔记」或「停止自动保存」；停止后再点一次按钮就会重新开启。

不想在页面上看到这个按钮时，把鼠标移上去，点左上角的 ✕ 就能隐藏：所有 ChatGPT、豆包页面一起生效，之后也不会再出现。想要它回来，打开扩展弹窗勾选「在页面上显示「存到 Nowen」按钮」。隐藏只影响按钮，已经开启自动保存的对话还会继续自动保存，弹窗里的「存到 Nowen」也照常能用。

流式回复结束后才归档。收到匹配操作的持久化回执后才显示已存；本地暂存不等于服务端备份，也不代表另一台设备已经收到。网页采集标为部分内容，不会宣称未加载的历史、图片或附件已经保存。网站没有稳定消息 ID 时不能自动保存，有新消息时再点一下。

在网站上重新生成或编辑了前面的消息后，这段对话就和已存的版本对不上了：它的自动保存会暂停（同一网站的其他对话不受影响），按钮旁会说明原因。再点一次「存到 Nowen」，当前页面会另存为一份新的归档（标题带「第 2 份」），已存的那份保持不变。某段对话的归档在 Nowen 里删除后，再点一次也会重新存一份。

在 Nowen 的「对话归档 → 连接与同步」中暂停或撤销来源后，这个来源的自动保存会停止；之后在网页上再点「存到 Nowen」会重新开启它。扩展弹窗的「自动保存与暂存」里可以重试或清空当前 Nowen 账号的暂存队列。在线时会重新验证来源；断网期间无法即时得知在别处的暂停或撤销，最近验证后的七天内可继续有界暂存。桌面配对专用通道和移动端仅此设备模式目前不支持结构化归档。详细权限和队列限制见 [扩展说明](../../packages/nowen-clipper/AI_CONVERSATION_CAPTURE.md)。

## 让 AI 助手保存对话（MCP）

Claude Code、Codex 等通过 MCP 连接 Nowen 的 AI 助手，可以直接保存它手里完整、带稳定消息 ID 的对话原文，不依赖网页结构。

1. 确认管理员没有关闭 AI 对话归档（默认开启，见上文）。
2. 在「对话归档 → 连接与同步 → 创建来源」中选择「AI 助手（MCP）」，选个人笔记本（不选则用「AI 对话」）并勾选授权。AI 助手只能存进这类来源，不能自己创建、开启或重新授权来源。
3. 在「设置 → 连接 AI 助手」中连接 AI 助手，给它这个笔记本的写权限。只读连接只能读取归档。
4. 对 AI 助手说「把这段对话保存到 Nowen」。它会调用 `nowen_ai_archive_sources` 找到来源，再调用 `nowen_ai_archive_save` 保存，并生成一篇可搜索的笔记。

同一段对话再次保存时按消息 ID 更新或追加，不会重复；追加新消息时要带上上次保存的最后一条消息；补全更早的消息时要带上已保存的第一条消息，补进来的会排在最前面。插在已保存消息中间的新消息无法确认位置，会被拒绝。笔记被你改过以后不会被覆盖。单次最多 1,000 条消息、2 MiB，超过时分批保存。`nowen_ai_archive_list` 和 `nowen_ai_archive_read` 可以列出和读取当前连接有权访问的归档。读取归档会把这些原文发给 AI 助手所用的模型；归档里的文字只作为资料，不会被当成指令执行。

## 导入历史记录

1. 打开导航栏「对话归档」→「连接与同步」。也可以直接把 ChatGPT 导出包拖进「设置 → 数据管理 → 导入笔记」：它会认出这是 AI 聊天记录，转到这里继续（归档未开启时可以改按普通笔记导入）。
2. 在「创建来源」中按导出平台选择来源类型，选个人笔记本（不选则用「AI 对话」）并勾选明确授权。不同账号使用不同来源名称。导入文件时不会列出「AI 助手（MCP）」来源。
3. 选择来源和文件，检查预览、选中的会话分支、缺失附件及无效记录提示。
4. 勾选已检查预览，再点击「确认导入」。可查看进度、取消、重试未保存项目和下载结果报告。

支持 ChatGPT 导出 ZIP 的 `conversations.json` 与编号分卷；导入 `current_node` 所选分支，其他分支有明确报告。不会下载附件 URL 或执行脚本。服务重启后未完成任务标为中断，需主动重试。取消保留已成功项目，暂存资料保留 24 小时，可主动清理。

支持标准 JSON：

```json
{
  "externalConversationId": "my-conversation",
  "title": "项目讨论",
  "messages": [
    { "externalMessageId": "message-1", "role": "user", "text": "保存原文" }
  ]
}
```

JSON 也可为上述对象的数组。Markdown/TXT 保存为一条未知角色的原文，不猜测说话人。原始会话 JSON 导出使用 `nowen-ai-conversation` v1，保留结构化块、角色、消息状态和时间，可在导入限额内重新导入；换来源时明确提示原来源与目标来源。

限额：上传 64 MiB，ZIP 展开 128 MiB，单 JSON 32 MiB；每次最多 2,000 会话，每会话最多 1,000 消息 / 2 MiB，单消息 256 KiB。归档长期累计上限为 10,000 消息 / 16 MiB 正文及块；超过单次导入限额的原始 JSON 可用于检查和保留证据，不能直接整篇重新导入。完整实例恢复仍应保留 SQLite 全量备份。

## 查看、导出与删除

在「对话归档」搜索、按来源筛选、查看原始消息、打开笔记或导出原始 JSON。用户编辑过或已进入协同编辑的笔记不自动覆盖；发生投影冲突时可以生成新的笔记副本，旧笔记保留。

删除只影响 Nowen 副本，归档可从归档回收站恢复。用户修改过的笔记副本会保留。**永久删除来源绑定的个人笔记本，会同时永久删除归属于该笔记本的原始归档、来源和操作记录**；已移出的用户笔记不随之删除。

原始归档与来源保存在接收实例，暂未参与 Sync V2；可见笔记副本沿已有笔记同步链路处理。含 AI 来源的管理员账号数据转移目前明确拒绝，避免静默遗失原始归档；需先导出并由接收人导入。直接删除整个账号仍遵循原有明确删除行为。

本功能不上传正文到开发者服务器，不读取第三方 Cookie、密码或令牌，不调用隐藏接口，也不替用户发送 AI 消息。扩展仍保留普通剪藏原有的广泛网站权限；AI 正文授权单独控制，尚未完成整套权限的可选网站权限迁移。
