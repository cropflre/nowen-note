# AI 对话归档（v1.6.0 开发版）

[English](ai-memory.en.md) · [架构与权限](../architecture/ai-memory-hub.md) · [验收记录](../qa/ai-memory-hub-2026-11-05.md)

当前实现的是原始对话归档 MVP。长期记忆、记忆确认、跨 AI 上下文插入和记忆专用 MCP 尚未开放。ChatGPT/豆包适配器经过本地页面 Fixture 验证，真实网站改版、安装版和实际账号仍需验收。

## 保存当前网页会话

1. 在 Nowen Web Clipper 中登录自己的 Nowen HTTP 服务端。先在 Nowen 创建一个个人笔记本。
2. 打开 ChatGPT `/c/<id>` 或豆包 `/chat/<id>` 会话，再打开扩展。普通网页保留原有剪藏界面。
3. 选择个人笔记本，填写来源名称，点击「授权读取并预览当前对话」。安装扩展或打开页面本身不会授权读取 AI 正文。
4. 核对标题、完整可读取文字、数量和警告，再保存。网页采集标为部分内容，不会宣称未加载的历史、图片或附件已经保存。
5. 可选为**当前会话**开启自动保存。其他会话仍需单独授权；网站没有稳定消息 ID 时只支持首次手动快照。

流式回复结束后才归档。收到匹配操作的持久化回执后才显示实例已保存；本地暂存不等于服务端备份，也不代表另一台设备已经收到。桌面配对专用通道和移动端仅此设备模式目前不支持结构化归档。

在扩展中可以暂停当前会话、暂停或撤销来源，以及明确清空当前 Nowen 账号的暂存队列。在线时会重新验证来源授权；断网期间无法即时获知其他设备撤销的授权，最近授权/验证后的七天内可继续有界暂存。详细权限和队列限制见 [扩展说明](../../packages/nowen-clipper/AI_CONVERSATION_CAPTURE.md)。

## 导入历史记录

1. 打开导航栏「AI 记忆」→「连接与同步」，也可从数据管理的 AI 导入入口进入。
2. 创建导入来源，选择平台及个人笔记本，勾选明确授权。不同账号使用不同来源名称。
3. 选择来源和文件，检查预览、选中的会话分支、缺失附件及无效记录提示。
4. 勾选已检查预览，再点击「确认导入」。可查看进度、取消、重试未保存项目和下载结果报告。

支持 ChatGPT 导出 ZIP 的 `conversations.json` 与编号分卷；导入 `current_node` 所选分支，其他分支有明确报告。不会下载附件 URL 或执行脚本。服务重启后未完成任务标为中断，需主动重试。取消保留已成功项目，暂存资料保留 24 小时，可主动清理。

支持标准 JSON：

```json
{
  "externalConversationId": "my-conversation",
  "title": "项目讨论",
  "messages": [
    { "externalMessageId": "message-1", "role": "user", "text": "保存原文" }
  ]
}
```

JSON 也可为上述对象的数组。Markdown/TXT 保存为一条未知角色的原文，不猜测说话人。原始会话 JSON 导出使用 `nowen-ai-conversation` v1，保留结构化块、角色、消息状态和时间，可在导入限额内重新导入；换来源时明确提示原来源与目标来源。

限额：上传 64 MiB，ZIP 展开 128 MiB，单 JSON 32 MiB；每次最多 2,000 会话，每会话最多 1,000 消息 / 2 MiB，单消息 256 KiB。归档长期累计上限为 10,000 消息 / 16 MiB 正文及块；超过单次导入限额的原始 JSON 可用于检查和保留证据，不能直接整篇重新导入。完整实例恢复仍应保留 SQLite 全量备份。

## 查看、导出与删除

在「对话归档」搜索、按来源筛选、查看原始消息、打开笔记或导出原始 JSON。用户编辑过或已进入协同编辑的笔记不自动覆盖；发生投影冲突时可以生成新的笔记副本，旧笔记保留。

删除只影响 Nowen 副本，归档可从归档回收站恢复。用户修改过的笔记副本会保留。**永久删除来源绑定的个人笔记本，会同时永久删除归属于该笔记本的原始归档、来源和操作记录**；已移出的用户笔记不随之删除。

原始归档与来源保存在接收实例，暂未参与 Sync V2；可见笔记副本沿已有笔记同步链路处理。含 AI 来源的管理员账号数据转移目前明确拒绝，避免静默遗失原始归档；需先导出并由接收人导入。直接删除整个账号仍遵循原有明确删除行为。

本功能不上传正文到开发者服务器，不读取第三方 Cookie、密码或令牌，不调用隐藏接口，也不替用户发送 AI 消息。扩展仍保留普通剪藏原有的广泛网站权限；AI 正文授权单独控制，尚未完成整套权限的可选网站权限迁移。
