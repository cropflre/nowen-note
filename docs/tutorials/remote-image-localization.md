# 网络图片转存

在「设置 → 数据管理 → 网络图片转存」打开工具，点击「开始转存全部笔记图片」。系统自动扫描全部个人笔记，将网络图片保存为附件并替换成功下载的图片引用，无需选择笔记或手动分批。

- 不处理工作区、回收站中的笔记；没有写权限、已锁定或处理期间发生冲突的笔记会跳过。
- 下载失败时保留原图片链接，可展开失败明细并重试失败项；成功转存的图片不会再次作为网络图片下载。
- 可关闭工具窗口，稍后重新打开查看进度。后台服务须保持运行；服务重启导致任务中断时，可点击「重试失败项」处理未完成的笔记。
- 「停止转存」停止后续处理，已经成功保存的图片会保留。再次开始会重新扫描，已转存的图片自动跳过。
- 同一图片主机的请求至少间隔 2 秒，收到 HTTP 429 时自动等待并重试一次；仍失败则保留原链接。关闭窗口与停止任务是两个独立操作。

服务端的 `REMOTE_IMAGE_LOCALIZATION_MAX_NOTES` 控制自动扫描的每批笔记数，`REMOTE_IMAGE_LOCALIZATION_MAX_IMAGES` 和 `REMOTE_IMAGE_LOCALIZATION_MAX_TOTAL_MB` 限制临时下载缓存；达到批次或缓存上限后自动继续，不要求用户拆分个人笔记库。单张图片的大小、安全校验和写入前版本检查仍然生效。
