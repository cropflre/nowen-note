# 在手机上使用 nowen-note

> 在 Android 手机上安装和使用 nowen-note，随时随地记笔记。

---

## 安装方式

### 方式一：下载 APK

1. 访问 [Releases 页面](https://github.com/cropflre/nowen-note/releases)
2. 下载最新版 `.apk` 文件
3. 在手机上安装（需允许安装未知来源应用）

### 方式二：手机浏览器

直接在手机浏览器中访问你的 nowen-note 服务器地址，例如 `http://192.168.1.100:3001`。

---

## 移动端界面

移动端采用抽屉式布局：

- **默认**：显示编辑器
- **左滑/点 ☰**：打开侧边栏
- **点笔记**：切换笔记

## 登录同步模式下的文件夹密码

- 设置密码的文件夹及其子目录中的笔记，需要先在目录中解锁所有受保护的祖先文件夹。
- 配合新版服务端，联网加载列表时会一次确认密码目录的解锁状态，减少大量笔记造成的等待；打开正文仍单独确认权限，离线快照不会保留这次解锁确认。
- 未解锁时，“所有笔记”、收藏、标签和搜索均不显示这些笔记的正文预览。
- Android App 打开受保护笔记时需要联网确认解锁令牌仍有效；重新锁定后，已打开的正文、标签页和分屏会收起。
- 普通笔记仍可使用已缓存的目录信息离线读取。首次离线使用或目录权限、密码信息尚未缓存时，请先联网加载。
- 已有笔记若缺少自身的目录节点，将暂时隐藏并拒绝打开，不会改用 `notebookId` 猜测权限。只有带明确本地创建标记、尚未尝试发送的新笔记，才能继承已知目录链；该标记随本地数据库持久化，并在首次发送或收到远端同 ID 笔记时撤销。
- 同步请求失败时，草稿和待传队列仍会保留；若此时无法确认目录归属，请联网刷新目录后再打开。升级前没有明确创建标记的笔记也遵循这一规则。
- “仅此设备”模式使用独立本地空间，暂不支持服务端文件夹密码。

## 移动端操作

| 操作 | 方法 |
|---|---|
| 打开侧边栏 | 点击左上角 ☰ 菜单按钮 |
| 新建笔记本 | 侧边栏顶部 ＋ 按钮 |
| 新建笔记 | 选笔记本 → 新建笔记 |
| 更多操作 | 长按笔记本或笔记 |
| 移动笔记 | 长按笔记 → 移动到… |
| 搜索 | 侧边栏顶部搜索框 |

## 移动端编辑

编辑器在手机上完整可用：

- 点击正文区域弹出键盘
- 格式工具栏在键盘上方
- 支持所有富文本格式
- 支持图片粘贴和拖入
- 自动保存

---

## 常见问题

### Q：手机上打不开侧边栏？

确认是点击 ☰ 按钮，不是滑动。侧边栏以抽屉形式从左侧滑出。

### Q：编辑时键盘遮挡内容？

编辑器会自动滚动让光标可见。如果仍有问题，可以收起侧边栏获得更多编辑空间。

### Q：移动端和桌面端数据同步吗？

是的。登录同一账号，数据通过服务器实时同步。
