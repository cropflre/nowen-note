# 在手机上使用 nowen-note

> 在 Android 手机上安装和使用 nowen-note，随时随地记笔记。

---

## 安装方式

### 方式一：下载 APK

1. 访问 [Releases 页面](https://github.com/cropflre/nowen-note/releases)
2. 下载最新版 `.apk` 文件
3. 在手机上安装（需允许安装未知来源应用）

### 方式二：手机浏览器

直接在手机浏览器中访问你的 nowen-note 服务器地址，例如 `http://192.168.1.100:3001`。

---

## 移动端界面

移动端采用抽屉式布局：

- **默认**：显示编辑器
- **左滑/点 ☰**：打开侧边栏
- **点笔记**：切换笔记

## 移动端操作

| 操作 | 方法 |
|---|---|
| 打开侧边栏 | 点击左上角 ☰ 菜单按钮 |
| 新建笔记本 | 侧边栏顶部 ＋ 按钮 |
| 新建笔记 | 选笔记本 → 新建笔记 |
| 更多操作 | 长按笔记本或笔记 |
| 移动笔记 | 长按笔记 → 移动到… |
| 搜索 | 侧边栏顶部搜索框 |

## 移动端编辑

编辑器在手机上完整可用：

- 点击正文区域弹出键盘
- 格式工具栏在键盘上方
- 支持所有富文本格式
- 支持图片粘贴和拖入
- 自动保存

## 常见问题

### 两个同步选项有什么区别？

在 **设置 → 数据与同步** 中选择：

- **不同步，仅此设备**：新增和修改只保存在当前设备，不自动上传或接收更新。重启应用后仍保持关闭。服务器上此前已有的数据不会被删除。
- **我的 Nowen Server**：先保存到本机，再在后台自动同步。断网时照常编辑，恢复网络后自动补传。

关闭同步不会退出账号或切换笔记；重新开启后，关闭期间新增和修改的内容会自动补传。侧栏底部只保留“设置”，当前账号、登录记录和退出登录位于 **设置 → 账号与安全**。

### 没登录时写的笔记怎样同步？

选择“我的 Nowen Server”并登录账号，本机笔记会自动带入账号，开启同步后上传服务器。无需手动导入导出。

### 哪些设置随账号恢复？

编辑器模式、阅读密度、代码主题和导航模块等 UI 偏好在开启同步后随账号保存，关闭期间的修改只保存在当前设备，重新开启后自动补传。“移动端隐藏快捷栏”等设备设置只保存在此设备，不随账号同步。

### 怎样确认断网编辑是否已上传？

编辑器分别显示本机保存状态和后台同步状态：“已保存到本机”表示本机写入成功；“待同步 2”表示还有内容或附件等待同步；“已同步”表示当前没有待同步内容或附件。冲突会单独提示，可到 **设置 → 数据与同步** 处理。该页面也显示待同步数量、待传输附件和最后同步时间，并提供“立即同步”。

### Q：手机上打不开侧边栏？

确认是点击 ☰ 按钮，不是滑动。侧边栏以抽屉形式从左侧滑出。

### Q：编辑时键盘遮挡内容？

编辑器会自动滚动让光标可见。如果仍有问题，可以收起侧边栏获得更多编辑空间。

### Q：移动端和桌面端数据同步吗？

手机和电脑客户端都选“我的 Nowen Server”，连接同一服务器并登录同一账号，笔记就会自动保持一致。哪个设备选择“不同步”，哪个设备就不会自动上传或接收更新。电脑直接用浏览器访问服务器网页时，无需另开同步，网页操作的就是服务器数据。
