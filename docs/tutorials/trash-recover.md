# 如何恢复误删内容

删除的笔记、文件夹、脑图和轻量表格进入统一回收站，原资源 ID 和关联数据保留，直到永久删除。

## 查看与查找

点击导航栏「回收站」进入独立页面。可按「全部 / 笔记 / 文件夹 / 脑图 / 轻量表格」筛选，或搜索标题和原位置。每项展示原位置和删除时间。

## 恢复

点击条目的「恢复」，或勾选多项后点击「恢复」。优先恢复到原位置；需要恢复已删除祖先目录时会提示确认，并恢复与该目录同时删除的内容。更早删除的其他内容留在回收站。

恢复能力取决于内容及必要祖先目录的权限。原位置中无权查看的目录名称不会显示；无法恢复时列表会保留条目并说明原因。

## 永久删除与清空

点击条目的「永久删除」，或勾选多项批量删除。页面顶部「清空回收站」尝试删除当前空间中你可见的所有已删除内容，包含文件夹、脑图和轻量表格。

确认弹窗显示待处理数量。永久删除不可撤销，请确认内容不再需要；建议定期[备份](./backup-migrate.md)。

每项内容仍会经过权限和锁定检查。受保护内容及其所在非空目录保留，页面显示未完成原因。批量操作可能部分成功；一次最多勾选 500 项。锁定笔记可以先恢复、解锁，再移入回收站永久删除。

回收站不会自动清理。本次统一回收站不包含独立文件管理中的文件。

本教程基于 `release/v1.5.0` 当前实现。
