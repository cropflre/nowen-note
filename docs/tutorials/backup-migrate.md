# 数据备份与迁移

> 定期备份数据，防止意外丢失。支持跨服务器迁移。

---

## 数据位置

所有数据在 SQLite 数据库文件中：`data/nowen-note.db`

附件图片在：`data/attachments/`

---

## 备份方法

数据管理首页按目标提供四个入口：**立即备份、恢复数据、导入数据、导出数据**。同步状态和设置位于「同步」，同步不会代替备份。

完整备份与恢复是管理员的实例级操作，包含此实例中其他用户和工作区的数据。普通用户可按管理员授权导入或导出个人数据。

### 自动备份（推荐）

设置 → 数据管理 → 数据保护 → 开启自动备份。首页直接显示已保存的自动备份状态。

默认自动备份包含附件；具体时间、间隔、保留份数、SMTP 通知等设置位于「高级数据管理」。开启或关闭首页开关会直接保存，并保留已有调度设置。

### 立即备份（推荐）

设置 → 数据管理 → **立即备份**。默认创建完整备份，包含数据库、附件、字体、插件和相关配置。

在高级数据管理中配置并启用 WebDAV 后，立即备份会先保存当前实例的备份，再上传同一份文件。远端上传失败会明确提示，当前实例的备份仍然有效。自动备份是否上传远端由 WebDAV 中的自动上传设置控制。

备份保存在当前 Nowen 实例的备份目录中。在浏览器或手机连接服务器时，这指服务器的目录，不是浏览器或手机的存储空间。

桌面端、Web 端和 Android 端共用上述数据管理入口。桌面本机运行时备份位置显示「本机」，连接服务器时显示「Nowen Server」。Android 中的服务器备份只包含已到达服务器的数据，不包含手机尚未同步的修改；独立本机空间目前仅提供导入与导出入口，不展示服务器完整备份按钮。

### 手动备份

```bash
cp data/nowen-note.db "data/nowen-note.db.bak.$(date +%Y%m%d)"
```

### Docker 卷备份

```bash
docker-compose stop
cp -r ./data ./data-backup-$(date +%Y%m%d)
docker-compose start
```

## 恢复数据

### 应用内恢复

设置 → 数据管理 → **恢复数据**。列表汇总本机备份和已启用 WebDAV 的远程备份，显示时间、类型、大小及位置，也可手动选择备份文件。

远程备份先取回本机并校验，然后进入同一恢复预览流程；读取远端失败不会影响本机列表。单个远程备份或手动上传文件限制为 500 MB，更大的备份请放入服务器备份目录。

恢复前会显示影响范围，并要求确认和管理员身份验证。后端覆盖数据库前自动保存当前数据库的安全快照；这不是额外的完整附件备份。恢复会覆盖整个实例的数据，请核对后再执行。

### 手动恢复

```bash
docker-compose stop
cp data/nowen-note.db.bak data/nowen-note.db
docker-compose start
```

## 跨服务器迁移

### 方法一：数据库文件

1. 旧服务器停止服务
2. 复制 `data/` 目录到新服务器
3. 新服务器启动

```bash
docker-compose stop
scp -r ./data user@新服务器:/path/to/nowen-note/data
# 新服务器
docker-compose up -d
```

### 方法二：导入/导出

旧服务器：设置 → 数据管理 → 导出数据 → 下载

新服务器：设置 → 数据管理 → 导入数据 → 上传

导出流程中再选择数据范围和格式：**Markdown / ZIP** 适合 Obsidian、Typora 等软件；**Nowen 数据包** 适合迁移到另一台 Nowen Note。任务数据入口也位于导入/导出流程中。

导出包用于迁移选定空间，完整备份用于恢复整个实例，两者用途不同。
