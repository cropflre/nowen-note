# 登录和鉴权常见问题

> 解决登录失败、密码问题、2FA 等常见问题。

---

## 登录失败

### Q：提示「用户名或密码错误」？

1. 确认用户名和密码正确
2. 默认管理员：`admin` / `admin123`
3. 检查大小写
4. 联系管理员重置密码

### Q：提示「网络错误」？

1. 检查服务器地址是否正确
2. 确认服务器正在运行
3. 检查网络连接

桌面端出现 `Failed to fetch` 先检查本地后端是否启动、当前服务器地址和日志；它是请求未成功到达或完成的症状，不能据此判定密码错误。
新版登录页会显示请求目标与 HTTP 状态：有 `HTTP 401/403` 等响应时，按服务端返回的原因排查；显示「未收到 HTTP 响应」时，优先检查端口、证书、CORS/CSP 和反向代理。向维护者反馈时请提供脱敏后的目标地址、状态（或无响应）、出现时间和日志，**不要提供密码、令牌或本地凭据文件**。

### Q：便携版直接进入界面，是不是已经打开旧笔记库？

不一定。Full 桌面端的 `desktop` 是本机凭据托管的自动登录账号，自动登录不是应用密码锁。已有数据库若没有 `desktop` 账号，应用不会为它自动创建一个新的空身份。先在「数据管理 → 本地数据位置」确认正在使用的目录和 `nowen-note.db`，再核对当前账号；便携程序所在目录不一定是数据目录。

不要用新库直接覆盖旧库。迁移前先退出应用并备份整个旧数据目录，包括数据库及 WAL/SHM、附件、设置和隐藏的本地凭据文件；不要上传或公开本地凭据。
「数据管理 → 本地数据位置」也会显示当前会话账号 ID；它不保证就是本地数据库的拥有者，请与旧版本的账号 ID、笔记数量核对。升级验收时，分别在默认与自定义数据目录，用旧便携版真实数据的**副本**检查登录、笔记与附件、重启后可见性；不要在原始目录直接试验。

若要协助确认 [#787](https://github.com/cropflre/nowen-note/issues/787) 已修复，请记录以下不含私密内容的结果：

1. 记录旧版 v1.4.13 与新版 v1.5.0 各自使用的数据目录；新版可直接查看会话账号 ID。旧库账号 ID 和笔记数量如需核对，应由维护者在备份副本上只读检查，不要在运行中的数据库上操作。
2. 在**副本**上验证同目录升级、自定义目录启动、修改过本地账号密码后的手动登录，以及重启后笔记和附件是否仍可访问。
3. 如仍出现登录错误，记录登录页显示的是「连接探测失败」「未收到 HTTP 响应」还是具体 HTTP 状态；同时记录发生时间和已脱敏的请求目标。

不要将原数据库、WAL/SHM、附件或 `.local_account_secret` 上传到公开 Issue；需要进一步排查时先与维护者约定安全传递方式。

### Q：修改了桌面本地账号密码后无法自动登录？

v1.5.0 起，启动流程不会因登录失败而重置已有 `desktop` 账号的密码。可先用自己设置的密码手动登录；若需要恢复本地自动登录，请确认数据目录和备份后，在「数据管理」显式选择「恢复本地自动登录」。此操作会将该账号密码重置为本机托管凭据，并使旧登录会话失效，但不会删除笔记或附件。

### Q：Docker 部署后打不开？

1. 确认 Docker 容器正在运行：`docker-compose ps`
2. 检查端口映射是否正确
3. 查看日志：`docker-compose logs`

## 密码问题

### Q：忘记密码？

管理员可以帮普通用户重置密码。

如果是管理员自己忘记密码：

```bash
# Docker 环境
docker-compose exec backend npx tsx -e "
const Database = require('better-sqlite3');
const bcrypt = require('bcryptjs');
const db = new Database('data/nowen-note.db');
const hash = bcrypt.hashSync('新密码', 10);
db.prepare('UPDATE users SET passwordHash = ? WHERE username = ?').run(hash, 'admin');
console.log('密码已重置');
"
```

### Q：密码修改后其他设备需要重新登录吗？

修改密码后，其他设备的 JWT 会在到期后失效，需要重新登录。

## 两步验证（2FA）

### Q：手机丢失了怎么办？

使用恢复码登录。登录后在安全设置中重新配置 2FA。

### Q：验证码总是不对？

1. 确认手机时间准确（2FA 验证码基于时间）
2. 确认使用的是正确的验证器 App
3. 尝试输入下一个验证码（可能刚好跨时间窗口）

### Q：如何关闭 2FA？

登录后 → 安全设置 → 两步验证 → 关闭 → 输入当前验证码确认。

## 体验账号

### Q：体验账号有哪些限制？

- 无法修改密码和用户名
- 无法启用/关闭 2FA
- 数据可能被定期重置

### Q：如何从体验账号转为正式账号？

体验账号无法升级。需要管理员创建新账号，或自行部署。

---

## 快速登录

### Q：什么是快速登录？

快速登录是一种无需输入密码的登录方式，适合个人设备。启用后下次打开会自动登录。

### Q：如何启用快速登录？

登录时勾选「记住密码」或「自动登录」。
