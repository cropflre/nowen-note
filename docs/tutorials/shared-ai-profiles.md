# 管理员共享 AI 配置

系统管理员可以统一维护模型服务，向指定账号开放使用。成员无需重复填写服务地址、API Key 或自定义请求头，仍可保留自己的个人配置。

## 管理员设置

1. 打开“设置 → AI 设置”，进入共享配置管理。
2. 新建共享配置，填写服务商、服务地址、密钥和聊天模型；也可以从已保存的个人配置发布。
3. 勾选允许使用的成员并保存，使用连接测试确认服务器能够连接模型服务。
4. 后续可修改模型或密钥、调整成员、暂停或删除共享配置。更新后新调用采用最新设置。

从个人配置发布后，共享配置是独立资源；修改原个人配置不会连带修改共享版本。管理接口仅允许系统管理员的登录会话操作，工作区管理员身份不自动获得此权限。

## 成员使用

1. 打开 AI 设置或聊天窗口的模型选择器。
2. 选择标记“管理员提供”的共享配置并启用。
3. 使用聊天、编辑器 AI、知识问答、任务 AI 或符合模型能力要求的 AI 助手。需要个人服务时可以切回个人配置。

成员看不到共享服务的地址、密钥或请求头。模型使用权限不增加笔记、附件或工作区访问权限。共享模型和个人模型都受 AI 总开关控制。

被撤权、暂停或删除后，新的模型调用停止放行，并提示重新选择。正在发送或返回中的上游请求可能完成。系统不会自动换用个人模型产生其他费用。

## 客户端与连接

- Web 和直接连接服务器的桌面、移动客户端使用该服务器的共享目录。
- 桌面 Full 在本地后端运行并绑定远程同步账号时，可读取绑定服务器的共享模型，通过服务器代为调用模型；本地检索、工具执行和保存仍在原链路完成。客户端只保存公开模型信息与选择，不下载共享密钥。
- 桌面 Full 的共享管理入口管理当前本地实例；团队服务器的配置与成员授权请通过团队服务器网页管理。
- 切换服务器、远程账号或停止桌面同步连接后，原远程共享选择失效，需要重新连接或选择；仅本机移动模式不访问共享服务器。
- 使用共享功能需要服务器和客户端支持相应接口；旧服务器仍可使用个人配置。

共享聊天配置不自动提供 Embedding 服务。向量索引继续使用独立的个人 Embedding 配置，未配置时知识问答可使用现有关键词检索降级。

## 备份

共享配置和授权保存在服务器数据库，完整服务器备份包含这些数据；普通笔记导出或同步不会分发共享凭据。恢复或迁移服务器时，应保护包含模型密钥的完整备份。

本功能的本地自动化回归不等于所有客户端真机或第三方模型服务已完成验收。
