# 微信文章采集

安装、授权并启用后，复制公众号文章链接，返回 Nowen，确认是否采集；也可在插件页面粘贴一篇或多篇链接。自动保存到个人「微信收件箱」，可查看进度、打开笔记和重试失败项。

1.2.0 使用 sandbox-js，无需公众号密钥、回调地址、扫码绑定、Cookie 或 Action 参数。剪贴板只识别公开微信文章链接，用户确认后才创建任务，可关闭提示。桌面端返回应用时检查；Web 支持粘贴识别，自动读取需浏览器授权。

指定公众号可粘贴该公众号的文章链接。按名称获取全部历史文章暂不支持；微信验证页会报告失败，不冒充文章保存。

[使用、边界及验收说明](../../../docs/developer/wechat-capture.md)

打包（仓库根目录）：

```sh
cd examples/plugins/wechat-capture
node ../../../packages/nowen-plugin-cli/bin/nowen-plugin.mjs pack
```

源码包尚未等同于签名市场发布。旧采集队列与笔记保留，升级沿用原插件 ID。
