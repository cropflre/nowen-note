# 华为审核信息填报稿（2026-11-18 驳回后）

用途：直接复制到 AGC「版本信息 → 应用审核信息」与「审核说明」。括号内为需替换的实际值，不要原样提交。

## 一、应用审核信息

| 字段 | 填写内容 |
| --- | --- |
| 账号 | （专用审核账号，例如 review@nowen.cn） |
| 密码 | （固定密码，不要一次性验证码） |
| 服务器地址 | http://note.nowen.cn（若 hm.nowen.cn 已修好，填 https://hm.nowen.cn） |
| 备注 | 打开应用 → 设置 → 数据与同步 → 我的 Nowen Server → 填入上方服务器地址 → 用上方账号登录。登录后笔记、附件、同步、账号与安全、数据管理均可正常使用。 |

填写前自检：

- **不要填 `119.91.135.176:7673`**：该地址直连会被网关拦成 "Access Temporarily Unavailable"，只有域名可用。
- 线上 `/api/auth/register/config` 返回 `allowRegistration: true`，`userCount: 258`，说明这是**生产服务器且开放注册**。审核账号必须提前建好并在审核期保留，不要让审核员自行注册。
- 账号内预置 2–3 篇示例笔记、1 个笔记本、1 个附件，避免审核员看到空列表。
- 账号不能含真实个人笔记、真实令牌或生产密钥；不要给管理员角色。
- 服务器有效期覆盖整个审核周期，审核期间不要改密码、不要停服。

## 二、审核说明（300 字以内，可整段复制）

弄文笔记是本地优先的私人笔记应用。不登录也可进入「仅此设备」空间，新建、编辑、保存笔记，重启应用后内容仍在。

服务器登录与多设备同步属于可选功能，需要用户自行部署或使用可信服务方提供的 Nowen Note 服务端。为便于审核，已在上方「应用审核信息」提供可用的测试服务器与测试账号：打开应用 → 设置 → 数据与同步 → 填入服务器地址 → 使用测试账号登录，即可查看笔记、附件、同步及账号相关页面。

应用不申请通讯录、位置、相册等权限，仅在用户主动选择文件时读取所选内容。测试账号中的内容均为示例数据。

## 三、截图清单（重拍用）

统一用免登录可走通的界面，避免审核员在应用里找不到截图中的内容。

| 序号 | 画面 | 要求 |
| --- | --- | --- |
| 1 | 笔记列表 | 有 3 条以上示例笔记，标题为中文 |
| 2 | 富文本编辑 | 光标在正文，键盘可收起，避免出现未完成按钮 |
| 3 | Markdown 编辑 | 显示渲染结果，不要出现调试信息 |
| 4 | 笔记本整理 / 搜索 | 体现分类或检索能力 |
| 5 | 设置 → 关于 | 可展示 APP 备案号与版本号 |

注意事项：

- 竖版 9:16，至少 1080×1920，3–10 张，以控制台当次提示为准。
- 不要出现真实姓名、手机号、服务器口令、内网地址。
- 若包内隐藏了 AI 入口，截图、应用介绍、一句话简介里都不要出现「AI 快记」「AI 问答」「智能生成」等字样。
- 若保留 AI 入口，则必须同时具备：控制台 AI 声明、生成内容显式标识、隐式标识证据，以及《AI 内容标识说明函》。

## 四、不要贴进控制台的内容

`store-listing.zh-CN.md` 里的旧「审核说明草稿」带有「尚未完成发布签名及全部上架验收，此草稿不能直接作为可发布声明」等内部备注，属于工程待办，不应出现在提交给审核员的文本里。
