# AI 对话采集（v1.6.0 开发中）

这项功能将当前页面可读取的 AI 对话存入用户配置的 Nowen 实例。原始归档使用 `/api/ai-memory`，普通网页剪藏继续使用现有链路。它不会替用户发送 AI 消息，也不读取第三方 Cookie、密码、令牌或隐藏网络接口。

Nowen 服务端默认开启 AI 对话归档，管理员可以在「设置 → AI 助手」中关闭。关闭时扩展会停止自动保存并提示 `AI_MEMORY_DISABLED`；没发出的内容留在本地队列，重新开启后在网页上再点一次「存到 Nowen」即可发送。

## 使用

1. 在扩展设置中登录包含 AI 归档接口的 Nowen 服务端；桌面配对专用的 `/api/local/clipper` 通道尚不支持结构化 AI 归档。没登录就点保存时，扩展会打开设置页。
2. 打开 ChatGPT `/c/<id>` 或豆包 `/chat/<id>` 会话，页面右侧会出现「存到 Nowen」按钮。
3. 点一下。这次点击才会读取聊天正文；仅打开页面或弹窗不会读取。当前页面可见的整段对话存进个人空间的「AI 对话」笔记本（没有会自动创建）。页面提供稳定消息 ID 时，这段对话之后的新消息会自动保存。扩展弹窗里的「存到 Nowen」按钮效果相同。
4. 按钮显示「已存 · 自动保存中」或「已存 · 点击更新」，表示收到匹配操作 ID、来源 ID 和版本的持久化回执；「正在保存…」表示内容还在扩展里暂存，不代表服务端备份或其他设备已收到。所有网页快照都标为「部分」，不会假定未加载的历史消息已经保存。

第一次保存时自动创建以网站命名的来源（「ChatGPT」「豆包」），同一 Nowen 账号下这个网站的其他对话共用它；页面提供明确的可见账号标识且与原来源不同时，另建来源。按钮在扩展自建的封闭 Shadow DOM 里，只响应真实点击；页面脚本合成的点击不会读取或保存任何内容。页面只能得到「未保存 / 保存中 / 已存 / 出错」和是否自动保存，拿不到 Nowen 地址、来源或笔记信息；「打开笔记」由扩展后台打开新标签页。

网页没有稳定消息 ID 时不能自动保存，有新消息时再点一下。正在输出的回复不保存，生成结束后仍使用同一个平台消息 ID。

## 停止、冲突与来源

- 鼠标移到页面按钮上可以「停止自动保存」（弹窗里是「停止自动保存这段对话」），只停这段对话；再点一次「存到 Nowen」重新开启。
- 在 Nowen「对话归档 → 连接与同步」中暂停或撤销来源后，这个来源的自动保存会停止，待发送内容保留；之后再点「存到 Nowen」会把来源重新设为允许并开启。点击就是用户的同意，API Token 仍然不能自行开启或重新授权来源。
- 重新生成或编辑了前面的消息、归档在别处更新过、页面消息没有稳定 ID 却内容有变，或归档已在 Nowen 中删除时，服务端拒绝更新这份归档：只暂停这段对话的自动保存（同一来源的其他对话不受影响），按钮旁说明原因。再点一次时，只有当等待发送的内容都已出现在当前页面上，才移除这些等待项，并把当前页面另存为新副本（会话标识加 `~2`、`~3`…，标题加「第 2 份」）；原归档不变。等待项还在发送，或有内容不在当前页面上时，拒绝另存并提示先在弹窗里重试或清空暂存。
- 弹窗「自动保存与暂存」中的「清空当前账号暂存队列」需要确认，只清理当前 Nowen 实例、当前 Nowen 用户的本地 AI 队列。已经发出的请求可能已经保存，清空不能撤回服务端结果。
- 旧版扩展里撤销的来源不会再用于新的点击；这段对话还有它的待发送内容时，先在弹窗里重试或清空。

在线时，每轮自动保存前会查询来源是否仍允许、是否开启自动保存。服务端暂停、撤销或 401/403/404 会停止此来源的所有本地观察器。网络失败或 5xx 时，最近一次点击或验证后的 7 天内允许继续本地暂存，以保留离线聊天。**离线期间无法即时得知在其他设备上的暂停或撤销**；超过这个窗口停止自动保存，需要再点一次按钮。

## 本地队列与恢复边界

- 正文暂存在 `chrome.storage.local` 的 `nowenAIArchiveV1` 中，最多 40 项、3 MiB；达到限制后明确报错，不删除先前内容。
- 暂存包含 Nowen 服务器完整路径、稳定用户 ID、来源账户和会话 ID；访问令牌和刷新令牌不写入 AI 队列。切换账号或服务器后不发送原作用域队列。
- 每个请求使用固定操作 ID。可能已经发到服务器的请求不再改写；只有新快照完整包含原消息且内容完全相同时，才合并尚未发送的快照。部分页面快照不会删除未出现的旧消息。
- 网络故障使用退避，最多自动重试 8 次、7 天；超限后保留内容并停止自动重试，需人工处理。7 天是自动重试窗口，**不会静默清除过期正文**。
- 版本冲突不会自动改用服务端新版本重发。服务端返回错误或不匹配的回执时保留请求，不能将 HTTP 200 当作已保存。
- 每次 Service Worker 启动都重建一分钟的恢复闹钟。浏览器关闭时不保证提交成功；只有实际落盘的本地队列能够在重新打开后恢复。
- 浏览器清理存储、扩展卸载或配额异常可能破坏本地暂存。本功能不宣称浏览器本地存储经过静态加密。

## 浏览器权限

现有普通剪藏保留 `<all_urls>` 和已有 `activeTab` / `scripting` 等权限，避免破坏网页、截图和图片下载能力。本次只新增 `alarms`，用于唤醒有界重试队列。**已有的广泛浏览器权限不等于 AI 正文采集授权**：只有用户点击「存到 Nowen」才会读取正文，自动保存也只在点过按钮的会话里观察页面。

本阶段没有将既有宿主权限迁移到可选网站权限。后续 Chrome Web Store 提交前，需要单独核验权限迁移与隐私披露；不能把本地 Fixture 通过等同于商店合规已验收。

## 支持与验证

| 平台 | 实现范围 | 本地 Fixture | 真实网站 |
| --- | --- | --- | --- |
| ChatGPT | `/c/<id>` 可见消息（2026 年 11 月的新页面结构：`data-user-message-bubble`、`data-response-body`、`data-talvt-turn-state`；旧结构 `data-message-author-role` 仍支持）、页面按钮一键保存、点过按钮的会话自动保存；回复里 ChatGPT 标为不复制的引用标签不保存 | 已覆盖 | 页面按钮已出现，保存待人工验收 |
| 豆包 | `/chat/<id>` 的已识别消息容器，稳定 ID 缺失时关闭自动保存 | 已覆盖 | 待人工验收 |
| Claude / Gemini / DeepSeek | 普通网页或选区剪藏 | AI 专用适配器未实现 | 未宣称支持 |

当前 DOM 选择器是保守适配，网站改版时明确失败并提示普通选区剪藏。真实网站可能没有所需消息 ID 或使用其他结构；不得因为 Fixture 通过就宣称兼容。图片、附件、音频与不可见工具结果不下载，不伪装成完整归档。CSS 隐藏、ARIA 隐藏、脚本和模板内容不进入 AI 快照。

## 开发验证

```sh
npm run lint
npm test
npm run build
```

`tests/fixtures/` 是受控模拟页面，不包含真实用户聊天。测试覆盖点击前零正文读取、按钮只认真实点击、一键保存与来源复用、Markdown/代码/表格、CSS 隐藏内容、未知结构、流式回复、暂停与撤销后再点击、页面切换、跨账号作用域、队列上限、回执验证、冲突只暂停单个会话并另存新副本。构建继续强制验证 `content.js` 为可直接注入的单文件经典脚本。
