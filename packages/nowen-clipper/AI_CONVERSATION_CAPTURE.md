# AI 对话采集（v1.6.0 开发中）

这项功能将当前页面可读取的 AI 对话存入用户配置的 Nowen 实例。原始归档使用 `/api/ai-memory`，普通网页剪藏继续使用现有链路。它不会替用户发送 AI 消息，也不读取第三方 Cookie、密码、令牌或隐藏网络接口。

## 使用

1. 在扩展设置中登录包含 AI 归档接口的 Nowen 服务端；桌面配对专用的 `/api/local/clipper` 通道尚不支持结构化 AI 归档。
2. 打开 ChatGPT `/c/<id>` 或豆包 `/chat/<id>` 会话，打开扩展。
3. 在下方保存位置选择**已有的个人笔记本**。填写来源账户名称；不同网站账号使用不同名称，这个名称是用户管理的本地来源标识。
4. 点击「授权读取并预览当前对话」。这次点击才会读取聊天正文；仅打开页面或弹窗不会触发正文采集。
5. 检查标题、完整文字预览、消息数量与警告。所有网页快照均标记为「部分」，不会假定未加载的历史消息已经保存。
6. 可选勾选「同时为此会话开启自动保存」，再确认保存。自动授权仅适用于这个**精确会话地址**；其他会话需要重新预览授权。
7. 「Nowen 已持久化到版本 N」表示收到匹配操作 ID、来源 ID 和版本的持久化回执。「本地待同步」仅表示扩展中暂存，不代表服务端备份或其他设备已收到。

网页没有稳定消息 ID 时，仅允许首次手动快照，不能自动保存。再次发生无法可靠匹配的内容变化由服务端明确拒绝；可改用普通选区剪藏。正在输出的回复不保存，生成结束后仍使用同一个平台消息 ID。

## 暂停、撤销与来源隔离

- 「暂停此会话」停止当前会话的自动采集。
- 「暂停此来源」停止同一个来源账户的所有已授权会话。
- 「撤销此来源」还会更新服务端来源授权，待发送内容保留。它不会删除第三方平台原文。
- 撤销后要重新绑定同一会话，需要先处理或明确清空原暂存队列，再填写新的来源账户名称重新预览授权。新授权生成新的账户作用域；旧操作不会被重定向到新来源。
- 「清空当前账号暂存队列」需要确认，只清理当前 Nowen 实例、当前 Nowen 用户的本地 AI 队列。已经发出的请求可能已经保存，清空不能撤回服务端结果。

扩展不把用户起的来源名称当成网站登录身份的证明。自动授权限定到精确会话 ID；如果页面提供明确的可见账号标识，标识发生变化也会立即停止自动保存。没有可靠账号标识时，不提供整站自动授权。网站账号切换后应重新检查来源名称和预览。

在线时，每轮自动采集前会查询来源是否仍获授权、是否允许自动保存。服务端暂停、撤销或 401/403/404 会停止此来源的所有本地观察器。网络失败或 5xx 时，最近一次明确授权或验证后的 7 天内允许继续本地暂存，以保留离线聊天。**离线期间无法即时得知其他设备撤销的授权**；超过这个窗口停止自动采集并要求重新确认。

## 本地队列与恢复边界

- 正文暂存在 `chrome.storage.local` 的 `nowenAIArchiveV1` 中，最多 40 项、3 MiB；达到限制后明确报错，不删除先前内容。
- 暂存包含 Nowen 服务器完整路径、稳定用户 ID、来源账户和会话 ID；访问令牌和刷新令牌不写入 AI 队列。切换账号或服务器后不发送原作用域队列。
- 每个请求使用固定操作 ID。可能已经发到服务器的请求不再改写；只有新快照完整包含原消息且内容完全相同时，才合并尚未发送的快照。部分页面快照不会删除未出现的旧消息。
- 网络故障使用退避，最多自动重试 8 次、7 天；超限后保留内容并停止自动重试，需人工处理。7 天是自动重试窗口，**不会静默清除过期正文**。
- 版本冲突不会自动改用服务端新版本重发。服务端返回错误或不匹配的回执时保留请求，不能将 HTTP 200 当作已保存。
- 每次 Service Worker 启动都重建一分钟的恢复闹钟。浏览器关闭时不保证提交成功；只有实际落盘的本地队列能够在重新打开后恢复。
- 浏览器清理存储、扩展卸载或配额异常可能破坏本地暂存。本功能不宣称浏览器本地存储经过静态加密。

## 浏览器权限

现有普通剪藏保留 `<all_urls>` 和已有 `activeTab` / `scripting` 等权限，避免破坏网页、截图和图片下载能力。本次只新增 `alarms`，用于唤醒有界重试队列。**已有的广泛浏览器权限不等于 AI 正文采集授权**：AI 控制器必须经过独立用户授权才会观察或提取正文。

本阶段没有将既有宿主权限迁移到可选网站权限。后续 Chrome Web Store 提交前，需要单独核验权限迁移与隐私披露；不能把本地 Fixture 通过等同于商店合规已验收。

## 支持与验证

| 平台 | 实现范围 | 本地 Fixture | 真实网站 |
| --- | --- | --- | --- |
| ChatGPT | `/c/<id>` 可见消息、手动预览、精确会话自动保存 | 已覆盖 | 待人工验收 |
| 豆包 | `/chat/<id>` 的已识别消息容器，稳定 ID 缺失时关闭自动保存 | 已覆盖 | 待人工验收 |
| Claude / Gemini / DeepSeek | 普通网页或选区剪藏 | AI 专用适配器未实现 | 未宣称支持 |

当前 DOM 选择器是保守适配，网站改版时明确失败并提示普通选区剪藏。真实网站可能没有所需消息 ID 或使用其他结构；不得因为 Fixture 通过就宣称兼容。图片、附件、音频与不可见工具结果不下载，不伪装成完整归档。CSS 隐藏、ARIA 隐藏、脚本和模板内容不进入 AI 快照。

## 开发验证

```sh
npm run lint
npm test
npm run build
```

`tests/fixtures/` 是受控模拟页面，不包含真实用户聊天。测试覆盖未授权零 DOM 读取、Markdown/代码/表格、CSS 隐藏内容、未知结构、流式回复、撤销、页面切换、跨账号作用域、队列上限、回执验证、冲突保留和来源重新绑定。构建继续强制验证 `content.js` 为可直接注入的单文件经典脚本。
