# create-nowen-plugin

Run `npm create nowen-plugin` to scaffold a Nowen Extension Platform V2 `sandbox-js` plugin.

Templates: `hello`, `content`, `ai`, `importer`, `exporter`, `connector`, and `automation`.
Generated projects include `dev`, `validate`, `build`, `test`, `doctor`, and `pack` scripts. Pass `--publisher` and `--repository` for non-interactive CI scaffolding.
